# specs/

기능별 spec·plan·tasks를 두는 폴더다. 작업 절차는 저장소 루트 `AGENTS.md`의 "Spec Kit 작업 절차"를 따른다.

## 번호 대역

| 담당 | 역할 | 대역 |
|---|---|---|
| A | 플랫폼·AWS·통합 | 001–100 |
| B | 수집·Bronze (+Kafka) | 101–200 |
| C | 데이터 계약·Silver·Iceberg | 201–300 |
| D | 분석·화면·RAG | 301–400 |
| E | 판정·AI 경고·MLOps | 401–500 |

- 폴더 이름: `<세 자리 번호>-<짧은-이름>` (예: `101-daily-gap-check`, A의 첫 spec은 `001-...`)
- 대역의 마지막 번호(`100`, `200`, …)도 그 담당의 번호다. 예: `200-...`은 B, `201-...`은 C.
- 자기 대역 안에서 가장 큰 번호의 다음 번호를 쓴다. 다른 담당의 대역은 쓰지 않는다.
- AI 에이전트에게 맡길 때는 담당을 알려준다. 예: `/speckit-specify (담당 B) 전날 수집 누락을 아침에 확인하고 싶다`
