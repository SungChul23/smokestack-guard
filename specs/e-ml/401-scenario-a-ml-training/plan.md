## Summary

대만 CEMS 단독 시나리오 A에서 공통 입력 검증·Feature 선택·시간 분할·평가 흐름을 재사용한다. N1/S1은 물질별 XGBoost 분류·회귀, RN1/RS1은 물질별 Random Forest 회귀로 구성한다. 최종 산출물은 N1-C, N1-R, S1-C, S1-R, RN1, RS1의 실제 학습·평가 결과다.

이번 작업은 계획 문서만 작성한다. spec 및 기존 파일은 변경하지 않고 research/data-model/contracts/quickstart/tasks 문서, 학습 코드와 테스트는 생성하지 않는다. 미확정 사항을 유지하라는 사용자 지시에 따라 일반 Plan 워크플로의 조사·추가 산출물 생성을 생략한다. 전체 Plan 워크플로 완료 또는 구현 준비 완료로 판정하지 않는다.

## Technical Context

**Language/Version**: Python 제안. 학습 런타임 버전은 SageMaker 실행 방식·라이브러리 호환성 확인 후 승인한다. 로컬 문서 준비에는 설치된 Python 3.11을 사용했다.
**Primary Dependencies**: XGBoost(분류·회귀), scikit-learn(Random Forest·평가), SageMaker 연동 SDK 제안. 입력 처리 패키지는 실제 파일 형식 확인 후 선택한다. 패키지 버전·설치·컨테이너는 미확정이다.
**Storage**: S3 ML-ready 입력 및 모델·평가 결과 저장. 실제 URI·파일 형식·기간·출력 구조는 데이터 수령 후 확정한다.
**Testing**: 향후 사용자 요청으로 계약·경계·Feature 제외의 최소 검증 후 최종 학습·평가를 진행한다. 이번에는 테스트·학습을 실행하지 않는다. 테스트 도구는 미확정이다.
**Target Platform**: AWS SageMaker AI, `ap-northeast-2`(서울). 인스턴스·컨테이너·IAM 역할은 미확정이다.
**Project Type**: 공통 배치 학습·평가 파이프라인. Serving API는 제외한다.
**Performance Goals**: 6개 결과물의 학습·평가와 근거 보존. 데이터 규모·처리 시간·성능 합격 수치는 실측 전 확정하지 않는다.
**Constraints**: 30분 시계열, 미래 60분 예측, 미래 정보 누수 금지, 원본 ppm·기준치의 Feature 포함 금지, 계약 변경 금지.
**Scale/Scope**: NOx·SO₂, 4개 계열·6개 결과물. 데이터 건수·분포·기간은 미확보 상태다.

## 공통 학습 설계

### 1. 입력 검증과 행 선택

- `tw_cems_ml_ready`의 35개 컬럼, 타입, `feature_version`, `label_version`, `quality_policy_version`을 승인 계약과 대조한다. 계약 위치·허용 버전·중복/오류 정책은 수령 후 확인한다.
- NOx는 `nox`, SO₂는 `sox`로 분리한다. 분류는 `classification_eligible`, 회귀는 `regression_eligible`이 참인 행을 사용한다.
- 식별·시각·원본값은 검증용으로 유지하되 모델 Feature 배열과 분리한다. `measure_value`, `standard_value`, 식별자, Label, 적격·버전 컬럼을 Feature에서 제외한다.
- Feature는 spec FR-004의 비율·여유율·Lag·변화량·가속도·이동통계·추세·시간 정보만 계약상 명칭으로 선택한다. 35개 입력 컬럼 전체를 모델 입력으로 사용하지 않는다.
- 30분 슬롯은 정확한 시각으로 대응하며 결측을 보간하거나 다음 행으로 건너뛰어 Label을 연결하지 않는다. `m_time`과 ML-ready 시각의 대응은 계약 확인 전 추정하지 않는다.
- 과거 3시간부터 미래 60분까지 기준치 변경이 있는 행을 제외한다. 변경 후 전체 필요 구간이 안정적인 행은 허용한다. 필요한 이력 또는 품질 근거가 없으면 검사 완료로 처리하지 않는다.

### 2. 시간 분할과 누수 방지

- 굴뚝·물질별 시계열을 분리하고 Train → Validation → Test의 시간 순서를 유지한다. 무작위 분할은 사용하지 않는다.
- 분할 비율·기간은 실제 데이터의 건수·기간·클래스 분포 확인 후 확정한다. 전체 굴뚝 공통 날짜 경계와 굴뚝별 경계 중 선택은 사용자 판단 대상으로 남긴다.
- 각 행의 미래 60분 Label 참조가 다음 분할로 넘어가지 않도록 경계 행 제외 방식을 적용한다. 경계 포함 규칙과 제외 범위는 시간 의미 확인 후 승인받는다.
- Feature는 예측 시점까지 이용 가능한 정보만 사용한다. 학습되는 전처리가 필요하면 Train에서만 적합한다. Test는 전처리·튜닝·임계값 결정에 사용하지 않는다.
- 물질별 XGBoost/RF 회귀에 동일 분할·동일 평가 행을 사용한다. 분류·회귀는 적격성이 다르므로 동일 행이라고 가정하지 않는다.
- 모델별·분할별 유효 행 수, 분류 양성/음성 수 및 제외 사유·건수를 기록한다. 부족한 데이터나 단일 클래스는 사용자에게 보고한다.

### 3. 모델별 목표와 초기 설정 제안

| 결과물 | 목표 | 알고리즘 |
| --- | --- | --- |
| N1-C / S1-C | 현재 비율 <90%이고 미래 30분 또는 60분에 ≥90% 진입하는 `label_entry_60m` | XGBoost 분류 |
| N1-R / S1-R | 정확히 60분 후 `label_ratio_60m` | XGBoost 회귀 |
| RN1 / RS1 | 위와 동일한 회귀 Target | Random Forest 회귀 |

90%는 확정된 Label 기준이며 분류 확률 임계값과 다르다. 100% 초과 회귀 Target은 보존한다.

초기 설정은 아래의 미실행 제안이며 성능·비용 보장 또는 확정값이 아니다. 데이터 수령 및 사용자 검토 후 채택한다.

| 알고리즘 | 최소 초기 제안 | 보류 항목 |
| --- | --- | --- |
| XGBoost 분류·회귀 | 트리 100개, 최대 깊이 3, 학습률 0.1, 고정 seed 42 | 클래스 가중치, 조기 종료, 탐색 범위, 실행 자원 |
| Random Forest 회귀 | 트리 100개, 최대 깊이 10, 고정 seed 42 | 잎 최소 표본 수, 병렬도, 튜닝 범위 |

분류 확률 임계값은 Validation으로 결정하고 Test 평가 전에 고정한다. Recall 우선 또는 F1 최적화 등 선택 목적·제약은 사용자에게 확인한다. Test 결과에 맞춰 임계값을 재조정하지 않는다.

### 4. 평가·비교·결과 보존

- 분류: PR-AUC, Recall/Precision/F1, 독립 위험 사건 탐지율, 오경보 분석. 사건 병합 규칙·오경보 단위·기준선·합격 수치는 사용자 확인 후 고정한다.
- 회귀: MAE/RMSE(%p), 동일 물질 XGBoost와 RF의 동일 조건 비교.
- ppm 환산은 해당 미래 시점 기준치와 계약상 단위·정의를 확인하여 검증한다. 미래 기준치를 입력 Feature로 사용하지 않는다. 시점·기준치 근거가 없으면 환산 검증 완료로 표시하지 않는다.
- 입력 버전·기간·분할 경계·유효 행·Feature 순서·설정·실행 식별자·모델 버전·예측값·평가 지표·아티팩트 위치를 함께 보존한다. 실제 출력 경로·저장 형식은 미확정이다.
- 공통 흐름을 N1에 먼저 적용한 뒤 S1/RN1/RS1로 확장하는 순서를 제안한다. 실제 학습·평가 및 실행 방법 문서까지 완료해야 최종 기능 완료로 판정한다.

### 5. SageMaker 실행 방향

승인된 입력·설정으로 Training Job을 실행하고 모델 아티팩트·평가 결과를 보존하는 구조를 사용한다. 실행 진입점은 공통 처리와 모델 설정을 재사용한다. 6개 결과물을 각각 Job으로 실행할지 묶어서 실행할지, SDK/컨테이너·인스턴스·IAM·출력 경로·버전 관리 방식은 미확정이다. 이번에는 AWS 조회·생성·실행·배포를 수행하지 않는다.
