# 결정 근거

- 대화 원문 수정 대신 검증된 파라미터의 새 복사본을 만든다. 기존 요청을 덮어쓰지 않는다.
- 마지막 성공 호출만 찾지 않고 활성 초점을 검사한다. 문서/실패/미완료 요청 뒤 과거 측정 기록으로 후퇴하지 않는다.
- 기존 context-policy의 KST 달력·range 검증을 재사용한다. ‘어제’와 직전 날짜의 전날을 구별한다.
- 프론트 UI의 완료 버튼을 운영 실행 증빙으로 쓰지 않는다. 신뢰된 실행/전달 어댑터가 없으면 기록을 완료로 만들 수 없다.
- 실행기가 아직 없어 테스트 전용 어댑터를 별도 시연에서만 사용한다. 이는 실제 측정값 조회 정확도를 검증하는 작업이 아니다.
