# 구현 계획: 검증된 질의 PATCH

2026-11-16 · [명세](spec.md). 브랜치 변경 없음.

## 기술 환경·구조

기존 CommonJS 라우터·Kiwi·작업대 번들을 유지한다. `query-router/conversation-session.js`가 기존 tool-session/rag-pipeline 세션을 감싸며 독립 분류 전에 후속 여부를 검사한다. 도구 catalogue나 SQL 계약은 추가하지 않는다. 새 패키지·AWS·LLM API 비용 없음.

- 실행/전달 콜백은 생성 시 신뢰된 코드에서만 주입한다. 입력 JSON의 success/confirmed는 실행 완료의 근거가 아니다.
- 실행기 없는 기본 모드는 준비만 반환한다. 시연은 별도 simulation 모드로 생성한 세션에서만 허용한다.
- parentQueryId·원문·canonical 파라미터·필드별 출처·receipt reference를 최근 10건, 초점 15분 동안 메모리에 보관한다. UI 선택·자유형 답변에서 상속하지 않는다.
- 기존 검증기로 새 후보를 다시 검증한다. context-policy로 달력·상대 기간을 절대 구간으로 고정한다. 종료는 달력 기준 반열린 구간이다.
- 최초 지원: read_values/aggregate_values의 날짜·단일 NOx/SOx 변경. 이전 조회기간이 정확한 하루일 때만 전날 이동. 법령·순위·화면·다중 변경·모호한 대상은 자동 PATCH하지 않는다.
- 후속 확장: `conversation-language.js`의 전체 문장 일치 문법으로 짧은 조사·존댓말·공통 물질 별칭을 정규화한다. 중립 확인·답변 표현 선호와 상태 질문은 최대 3턴까지 초점을 유지하고 건너뛴 발화를 감사 기록에 남긴다. 도구 미실행을 중립성의 근거로 사용하지 않는다.
- 작업대는 입력 변경 시 화면·이전 클릭만 무효화하고 대화 상태는 새 입력의 의미가 판정될 때 전환한다. 비동기 검색 응답은 턴별 façade로 격리해 이전 응답이 새 턴의 로딩 상태를 덮어쓰지 못하게 한다.
- 작업대 입력은 동일 대화 세션을 사용한다. 별도 continuity.html에서 실제 Kiwi와 테스트 전용 실행/전달 콜백을 시연한다. 운영 화면·분리 프론트에는 아직 실행기/대화 UI를 배포하지 않는다.

## 원칙 점검

수집·원본·AWS·Silver·학습 계약 변경 없음. 비밀값 사용 없음. actual과 simulation 기록을 분리한다. 실행 준비를 실제 조회 성공으로 표시하지 않는다. 기존 경계 검사 및 근거 검색을 우회하지 않는다. 명세 체크리스트 6/6.
