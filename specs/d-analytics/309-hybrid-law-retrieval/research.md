# 설계 근거

- FastEmbed는 ONNX CPU 로컬 임베딩과 다국어 MiniLM 384차원 모델을 지원한다. https://qdrant.github.io/fastembed/examples/Supported_Models/
- 자료가 작으므로 정규화 벡터의 전체 내적 검색으로 시작한다. 의미 검색을 위해 DB 서버가 필수는 아니다.
- 임베딩 모델 다운로드는 공개 가중치 확보이며 문서·질문을 외부 서비스에 전달하는 추론 호출이 아니다. 암묵적 HF 토큰 사용을 비활성화한다.
- 검색은 기존 정확 조회와 필터를 우선하고 의미 후보만 추가한다. 법령명·기준일·명령/자체개선·직접 근거 요구를 유사도로 대체하지 않는다.
- 기존 문자열 검색과 실제 의미 검색의 후보 적중을 분리해 비교한다. 검색 개선과 답변 품질을 같다고 주장하지 않는다.
