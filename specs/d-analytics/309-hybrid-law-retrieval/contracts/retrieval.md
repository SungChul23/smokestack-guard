# 검색 경계

- POST /api/vector-candidates: loopback·Host·Origin·로컬 작업대 토큰·JSON·질문 1~1000자 검사. 임의 파일 경로·URL·모델명·SQL은 입력받지 않는다.
- 반환 후보는 기존 corpus ID에 매핑한다. 질문·corpus 지문이 일치할 때만 사용한다. 변경된 원문에는 재검색한다.
- 기존 정확 조회·판본 미확보·범위 밖·금지·문서 미확보 가드를 우회하지 않는다. 원래 requiredTopics의 직접 근거는 여전히 필요하다.
- 모델 또는 인덱스 실패 시 검색 실패와 근거 미확보를 구분한다. 기존 문자열 대체를 명시하고 모델이 답을 대신 만들지 않는다.
- 비동기 준비 후 원문 요청 ID·권한·자료·취소 상태를 확인한다. 오래된 응답을 새 요청에 적용하지 않는다.
