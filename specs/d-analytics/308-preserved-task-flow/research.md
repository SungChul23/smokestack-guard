# 설계 결정

- 결정: 작업별로 원문 구간을 보존하고 지원 불가 판정을 별도로 둔다. 이유: 일반 검색의 성공이 위반 판단 성공으로 오인되는 것을 막는다. 기존 단일 search_documents에 두 작업을 넣는 방식은 폐기한다.
- 결정: 확인은 사용자 의사가 아니라 검색에 부족한 조건만 받는다. 이미 요청된 문서 검색은 재선택시키지 않는다.
- 결정: 일반 개요에서 명령의 특정 경로를 기본값으로 고르지 않는다. 문서 범위가 확정되면 관련 분기를 구분해 검색한다.
- 결정: 시설 자체개선의 유형은 사용자 확인만 사용한다. 저장 근거로 확인하지 않은 시설 유형을 검증된 사실로 표시하지 않는다.
- 결정: 모호한 분해를 규칙으로 강제하지 않는다. 명확한 원문 구간만 로컬 처리하며 다른 경우 기존 LLM 해석 후보·조건 확인을 유지한다.
- 결정: root/child 및 조건을 검사하고, 미지원·미확보·읽기 실패를 구분한다. 독립 의미 검수는 계속 필수다.
