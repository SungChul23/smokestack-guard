# 기능 명세: 로컬 TMS 자연어 조회·화면 라우터

**기능 번호**: 303 · D 분석·화면·RAG  
**작성일**: 2026-11-13(KST)  
**상태**: 일반 질의 기능 구현 전. 후속 화면 잠금·US6 실행 전 분기 검증 랩만 구현.  
**입력**: 사용자가 순차 확정한 `D/TMS_NL_Query_Router_Decisions_KO.md`의 11개 결정. 원본 설계는 `D/TMS_NL_Query_Router_Codex_Spec.md`이며 이번 범위 밖의 서버·모델·운영 기능은 자동 채택하지 않는다.

## 사용자 시나리오와 검증

### 후속 — 검색 실행 상태와 부분 답변 구분

도구 조건 준비, 실제 검색 상태, 답변 검증 완료를 별개로 표시한다. 자진개선 등 근거 원문의 적용 범위를 요약에서 보존하고 내용 정확성과 요청 전체 완료를 구분한다. 부분 근거는 검수자의 완료 표시로 전체 완료로 승격하지 않는다. 사용자가 확인한 보고 종류는 원문을 보존하며 후속 근거 선택에 반영하고 모델 추정과 구분한다. 인사평가 등 TMS 밖 자료는 검색하지 않는다. 검토용 표에서 보류한 것을 실제 분류 코드 수정으로 표현하지 않는다.

### 2026-11-15 오류 개선과 신규 질문 재검증

사용자는 일반 설명/개별 적용을 분리하고, 질문 조건 보존·근거 선별·출력 검증을 적용한 뒤 기존 실패와 성공 사례를 다시 검사하고 신규 질문도 늘려 검증하도록 승인했다. 일반 설명 직행은 전체 표현을 소비한 좁은 문법으로 제한하며 잔여 조건·다중 행위·부정은 해석 단계에 남긴다. 완료보고와 이행보고의 근거를 대체하지 않는다. 코드가 원문에서 발급한 인용 ID를 선택하게 하고 요약과 원문은 구분한다. 요약은 독립 검수 없이는 전달하지 않으며, 검색 상태·질문·기준일·출처·초안이 달라지면 검수 재사용을 허용하지 않는다. 로컬 공식 문서 읽기와 Luna 배치 범위를 유지하며 실시간 모델/운영 데이터 도구를 임의 추가하지 않는다.

### 2026-11-14 원문부터 RAG·Luna 답변까지 연결 검증

사용자는 생성·기존 질문을 실제 분류부터 문서 검색·Luna 답변까지 이어 실행하고, 최종 답변을 최초 원문 의도와 대조하도록 요청했다. 이번 실제 실행 확장은 로컬 공식 문서 읽기 1종이다. 기존 데이터·지도·예측 실행기는 자동 추가하지 않는다. 실제 Kiwi와 기존 tool-session 분류·조건/해석 확인을 거쳐 search_documents가 준비된 경우에만 302 검색을 호출한다. LLM_CANDIDATE의 해석·답변은 Luna 하위 에이전트 배치로 기록하며 실제 모델 API와 구분한다. 카드 응답은 시뮬레이션 사용자의 명시적 입력으로 기록하고 자연어 이해 성공으로 세지 않는다.

원문·형태소·초기 분기·확인 응답·승인된 요청·검색에 넘긴 원문/기준일·검색 원문·Luna 답변·원문 대비 판정을 동일 요청 ID로 추적한다. 미연결·조건 부족·거절은 임의로 검색 단계에 우회하지 않는다. 실제 실험실 화면과 메인 관제 화면의 연결 여부를 구분하고, 검색기에 직접 넣는 비교 실행은 end-to-end 성공으로 세지 않는다.

### US1 — 선택 굴뚝의 보관 측정값 확인 (우선순위 P1)

관제 사용자는 “이 굴뚝 NOx 얼마야?”라고 물어 선택한 대상의 보관값과 실제 측정시각을 확인한다.

**우선 이유**: 데이터와 대상을 잘못 연결하지 않는 가장 작은 독립 기능이다.

**독립 검증**: 같은 이름의 사업장과 서로 다른 굴뚝을 준비하고, 선택 또는 질문의 명시 대상에 맞는 원문·수치·측정시각만 반환하는지 확인한다.

**인수 시나리오**:

1. **조건** 사업장·굴뚝을 선택한 상태, **행동** “이 굴뚝 NOx 얼마야?”, **결과** 선택된 굴뚝의 보관 최신 응답을 측정시각·보관자료 표시와 함께 제공한다. 최신 응답이 상태문자/NULL이면 과거 숫자를 현재값처럼 대신하지 않는다.
2. **조건** 화면 A 선택, **행동** 식별 가능한 B를 질문에 명시, **결과** B만 조회하고 사용한 대상을 표시한다. 이름만으로 B가 유일하지 않으면 확인한다.
3. **조건** CO 등 잠금 물질 요청, **행동** 조회 제출, **결과** 잠금 이유를 안내하고 자료 조회·화면 변경·임의 대체를 하지 않는다.

### US2 — 애매한 조건 확인과 해석 보존 (우선순위 P1)

사용자는 무엇을 조회할지 모호할 때 선택지로 조건을 확정하고, 이전에 확정한 조건을 반복 입력하지 않는다.

**우선 이유**: 잘못 이해한 질문을 자동 실행하는 것을 방지한다.

**독립 검증**: 데이터 조회기와 화면 조작기의 호출 수를 세어 확인·차단 응답에서 실행 호출이 0인지 확인한다.

**인수 시나리오**:

1. **조건** “NOx 높은 굴뚝 10개”에 범위·지표 없음, **행동** 제출, **결과** 사업장/지역/전체 보관자료 범위와 측정값/기준대비율을 확인한다. 두 조건이 모두 확정될 때까지 실행하지 않는다.
2. **조건** 복합 부정·지시어·실제 원인 요구를 확정할 수 없음, **행동** 제출, **결과** 구체적으로 확인하거나 지원 불가를 안내한다. 단어 일부를 찾았다는 이유로 연산을 실행하지 않는다.
3. **조건** 확인 질문 이후 화면의 대상·기간·설정·자료 버전이 바뀜, **행동** 이전 선택지 클릭, **결과** 만료를 안내하고 현재 상태로 다시 확인한다.
4. **조건** 문장 전체의 의미를 확정하기 어렵거나 복합 부정이 있음, **행동** 사용자가 카드로 지원 요청을 선택, **결과** 분명한 조건만 보존하고 나머지는 직접 선택하게 한다. 원 요청을 바꾸는 경우 최종 요약을 확인한 뒤 새 요청으로 확정한다. 원문 해석 분기를 유지할 수도 있지만 실제 LLM 호출은 하지 않는다.
5. **조건** 잠금·예측 미연결·법적 적용성 요청, **행동** 결과 표시, **결과** 사유에 맞는 지원 대안을 명시적으로 선택할 수 있다. 금지 요청에는 우회 카드를 제공하지 않으며 단위/상태 정책 미확인을 사용자 클릭으로 확정 처리하지 않는다.

### US3 — 명확한 화면 명령 실행 (우선순위 P2)

사용자는 식별된 사업장으로 이동하거나 조회 기간·물질·표시 방식을 바꾸는 명령을 같은 화면에서 실행한다.

**우선 이유**: 기존 지도·그래프 기능을 재사용하여 질문을 실제 탐색으로 연결한다.

**독립 검증**: 관제/네이버 두 배경에서 사업장 선택·6/12/24시간·NOx/SOx 표시·측정값 표 열기의 변경과 안내가 일치하는지 확인한다.

**인수 시나리오**:

1. **조건** “사업장 170065로 이동해”처럼 명확한 지시, **행동** 제출, **결과** 즉시 화면에 반영하고 변경 대상을 안내한다. 질문용 최신값 조회 자체는 지도를 자동 이동하지 않는다.
2. **조건** “여기로 가”, 대상 없음, **행동** 제출, **결과** 대상을 확인하고 화면은 유지한다.
3. **조건** 오래된 비동기 요청 완료, **행동** 그사이 사용자가 다른 질문/굴뚝을 선택, **결과** 늦게 온 요청이 새 화면이나 답변을 덮지 않는다.

### US4 — 보관자료의 참고 계산과 제한된 목록·순위 (우선순위 P2)

사용자는 선택 굴뚝의 평균·최댓값과 정의가 명확한 최신 측정값 목록·순위를 확인한다.

**우선 이유**: 새로운 판정·모델 없이 확인 가능한 자료의 활용 범위를 넓힌다.

**독립 검증**: 숫자 0·상태문자·NULL이 섞인 표본에서 손계산과 비교하고, 사업장 방문 순서에 따라 전체 최신 순위가 달라지지 않는지 확인한다.

**인수 시나리오**:

1. **조건** 숫자 관측 0·10·20, 상태문자 1건, NULL 1건, **행동** 평균·최댓값 요청, **결과** 평균 10·최댓값 20, 계산 3건·제외 2건과 기간·제외 이유를 표시한다. 학습용 유효값이나 법정 평균으로 부르지 않는다.
2. **조건** 한국 날짜 2026-11-13, 보관 기준시각 2026-11-12 11:30, **행동** “어제”와 “최근 6시간” 각각 요청, **결과** 전자는 실제 날짜의 전일 전체, 후자는 보관 기준시각의 05:30~11:30으로 해석하고 일부 자료/결측을 표시한다.
3. **조건** 비율 정확히 100%, **행동** `초과`와 `100% 이상` 수치 조건, **결과** 각각 제외·포함한다. 화면상 초과 상태를 묻는 경우는 해당 상태 설정을 따른다.
4. **조건** 일부 사업장의 이력만 화면에 로딩됨, **행동** 전체 보관자료의 최신 순위 요청, **결과** 화면 로딩 이력과 별개인 전체 최신 출처를 사용한다. 전체 이력 평균 순위처럼 이번 실행기가 지원하지 않는 집계는 부분 자료로 대신하지 않는다.

### US5 — 공식 근거 검색과 미연결 기능 안내 (우선순위 P2)

사용자는 법령 근거 질문을 기존 문서 검색으로 전달하고, 모델 예측·원인 확정·법적 적용 판단이 미지원이면 그 경계를 확인한다.

**우선 이유**: 기존 302 기능을 보존하면서 측정 조회와 문서 근거를 구분한다.

**독립 검증**: 동일 질문·동일 문서 기준일의 기존 검색 결과와 비교하고, 확보하지 않은 날짜를 현재 법령으로 대체하지 않는지 확인한다.

**인수 시나리오**:

1. **조건** 확보된 문서 기준일로 “개선명령 이행보고 근거”, **행동** 검색, **결과** 기존 조문·출처·시행일을 표시한다.
2. **조건** 확보일 다음 날에 “현재 법령”, **행동** 검색, **결과** 그 기준일 문서 미확보를 안내한다. 이전 기준일을 자동 적용하지 않는다.
3. **조건** “1시간 후 초과 확률”, “왜 고장 났어”, “가동 중단해”, **행동** 제출, **결과** 모델 미연결·원인 근거 없음·제어 불가를 구분한다. 숫자·원인·의무를 생성하지 않는다.

### 경계 사례

- 동일 지역·이름·굴뚝 코드의 중복, 이름 변경, 선택 없음, 질문과 화면 충돌.
- 물질 생략 상태에서 화면에 NOx·SOx 모두 선택됨, 잠금 물질과 해금 물질이 섞인 복합 요청.
- 원문 0, 쉼표 숫자, 음수, 상태문자, NULL, 기준 0/NULL, 단위 미확인. 숫자 파싱은 운영상 정상 여부 판정이 아니다.
- 최신 응답의 측정시각이 오래되거나 상태문자인 경우, 요청 기간 밖 숫자로 임의 대체하지 않음.
- 서로 다른 굴뚝의 최신 측정시각 불일치, 화면 일부와 전체 보관자료의 모집단 차이.
- NOx·SOx는 낮지만 잠금 물질이 화면 대표 상태를 결정한 경우. 대표 상태를 NOx·SOx 원인으로 설명하지 않음.
- 날짜 0길이/역전·미확보·미래 구간, 사용자 경고선과 실제 응답 기준값의 혼동.
- 검색된 문서의 지시 문자열·입력 HTML·쓰기/삭제/설비 제어 요구, 확인 중 데이터 버전 변경.

### US6 — 실행 전 분기 한계 검증 (후속 요청, 우선순위 P1)

2026-11-13 사용자는 LLM을 붙이기 전에 질문을 대량 생성하고 정형/LLM 해석/확인/차단/미지원 분기의 정확성과 한계를 확인하도록 요청했으며 형태소 분석기로 kiwipiepy를 지정했다.

**독립 인수**: 실제 Kiwi의 토큰·품사와 요청별 기대/실제 분기·조건을 보관하고, 어떤 질문도 LLM·자료 실행기를 호출하지 않은 상태에서 불일치와 흐름도를 검토할 수 있어야 한다. 생성 문법 변형·무작위 불변조건을 실사용 자연어 정확도로 합산하지 않는다.

**인수 시나리오**: 원본 A~K 전 질문, 지원 문법 변형, 부정/조건 추가, 잠금, 권한/금지 요청, 미사용 자연어, 길이/유니코드 경계를 분리 시험한다. 분석기 예외와 의미 해석 실패를 구분한다. 안전하지 않은 정형 분기와 불필요한 LLM 분기를 모두 보고하며 불일치를 통과로 바꾸지 않는다.

## 요구사항

### 기능 요구사항

- **FR-001**: 질문의 명시 조건을 우선하고, 생략한 조건만 화면의 선택값으로 보충해야 한다. 단수 대상이 불명확하면 자동 선택하지 않는다.
- **FR-002**: NOx·SOx만 해금하고 나머지 5종은 잠금 안내해야 한다. 질문의 일부만 몰래 실행하거나 다른 물질로 대체하지 않는다.
- **FR-003**: 현재/지금은 보관 최신 응답으로 제공하며 대상별 측정시각·보관자료·실시간 아님을 명시해야 한다.
- **FR-004**: 달력 표현은 실제 KST 날짜, 최근 N시간은 화면 자료 기준시각으로 해석하고 시간 기준과 실제 조회 범위를 표시해야 한다.
- **FR-005**: 목록·순위에서 범위 또는 지표가 생략되면 사용자가 확정할 때까지 실행하지 않아야 한다.
- **FR-006**: 평균·최댓값은 숫자로 읽힌 값만 계산하고 0을 포함해야 한다. 상태문자·NULL 제외 이유와 계산·제외 건수·조회 기간을 제공해야 한다.
- **FR-007**: 기준대비율은 숫자 측정값과 양수 기준값이 있을 때만 계산해야 한다. 단위·기준값의 확인 수준과 출처를 표시하고, 확인할 수 없는 비교는 보류해야 한다.
- **FR-008**: 수치 조건의 `초과 >`·`이상 ≥`를 보존하고 화면 상태 분류와 별개로 처리해야 한다.
- **FR-009**: 임시 상태 단계·경계 변경은 화면과 에이전트 설명에 같은 버전으로 적용되어야 한다. 대표 상태의 대상·물질 범위와 사용자 경고선을 구분해야 한다.
- **FR-010**: 명확한 화면 명령만 즉시 반영하고 실제 적용 대상을 안내해야 한다. 일반 조회는 명시되지 않은 화면 변경을 일으키지 않아야 한다.
- **FR-011**: 일부 로딩 자료를 전체 보관자료 결과로 표현하지 않아야 한다. 최신 목록·순위는 전체 최신 자료, 선택 굴뚝 이력 계산은 해당 사업장·기간의 자료를 사용해야 한다.
- **FR-012**: 모든 실행은 허용된 조회·화면·기존 근거 검색에 한정하고, 확정되지 않은 조건·부정·비교·복합 작업은 확인 또는 지원 불가로 응답해야 한다.
- **FR-013**: 질문·문서·모델 출력이 원본 쓰기·삭제·외부 연락·설비 제어 실행으로 이어지지 않아야 한다.
- **FR-014**: 기존 법령 검색의 문서 범위·기준일·출처 제한을 유지해야 한다. 미래 예측·실제 원인·법적 의무를 생성하지 않아야 한다.
- **FR-015**: 질문 처리 결과는 사용 대상·물질·시간 기준·자료 버전·설정 버전·출처·계산 및 품질 내역을 추적할 수 있어야 한다.
- **FR-016**: 질문·확인 응답과 화면 상태가 충돌하거나 오래된 작업이 완료되면 재검증해야 한다. 늦은 결과가 새 화면/답변을 덮지 않아야 한다.
- **FR-017**: 로컬 내부 ID·단위 참조값·임시 판정을 팀 운영 계약이나 대한민국 전체 모집단으로 표현하지 않아야 한다.
- **FR-018**: 기존 지도 왕복 전환·드래그·차트 기간 이동·표·개인 설정·문서 검색을 유지해야 한다. 2026-11-13 후속 요청으로 질의와 화면의 물질 지원을 함께 제한한다. NOx/SOx만 사용하고 기존 TSP/HCl 카드는 잠금 안내를 표시하며 수치·선·하단 막대·표·축 계산에서 제외한다. 원문은 보존하고 팀의 지원 추가 시 공통 설정으로 해금할 수 있어야 한다.
- **FR-019**: 실행 전 분기 검증은 실제 Kiwi 분석 결과·독립적으로 작성한 기대 분기/조건·원본 카탈로그 ID·불일치를 요청별로 공개해야 한다. 형태소 분석 성공을 의미 이해 성공으로 취급하지 않는다.
- **FR-020**: 해석 불가/복합 의미의 LLM 후보 분기는 실제 호출 없이 기록해야 한다. 잠금·명확한 미지원·금지 요청·법적 적용성은 LLM 후보와 구분한다. 가짜 LLM 모양 후보를 구조상 수용해도 원 질문과의 의미 충실성을 검증하기 전 실행을 허가하지 않는다.
- **FR-021**: 분기 상황에 따라 부족한 조건 카드·요청 재작성 카드·지원 대안·카드 없는 차단/보류를 구분해야 한다. 이미 확인한 조건은 반복 질문하지 않으며, 원 요청을 바꾸는 재작성/대안은 최종 확인을 거친다. 선택지는 내부에 등록된 ID만 받고 재검증·만료·권한 검사를 우회하지 못해야 한다.

### 주요 개체

- **FR-024 (도구 우선 자연어 검증)**: 분석 전용 허용 도구 6종(측정 조회·집계·검색/순위·경고 근거·문서 검색·화면 조작)과 비교/예측 연결 대기를 명시한다. 도구 필수 조건에 맞춘 대량 질문을 실제 Kiwi로 분석하고 원문 전체 처리 여부·카드·LLM 후보·미지원·차단을 구분한다. LLM 모양 후보도 같은 검증기로 검사하고 누락 조건은 카드로 반환하며 완전한 후보도 의미 확인을 거친다. 실제 LLM/DB/도구 실행 없이 결과·실패·문맥·누락/위험 후보를 공개한다. 생성 문법 사례/독립 기대 초안/기존 검토/후보 JSON 검사를 구분하고 이를 실제 LLM 정확도나 운영 안전성으로 표현하지 않는다.

**2026-11-13 후속 사용자 확정 — 조건과 대화 문맥:** 빠진 대상·물질·시간을 체크된 UI 대상/차트 기간/보관 최신시각으로 자동 채우지 않는다. 명시한 조건 또는 이전 답변의 검증된 사실에서 확실히 이어지는 재료만 사용한다. 문맥 없는 ‘왜 경고’는 UI 선택만으로 확정하지 않으며 여러 후보는 참조를 확인한다. 지금은 실제 사용자 질문시각이며 보관 최신이나 지도 과거 시각으로 바꾸지 않는다. 과거 조회는 절대시각을 명시하거나 확인 카드로 확정한다. 이는 기존의 ‘이유는 지도 시각 자동 사용’ 및 ‘지금=보관 최신’ 초안보다 우선한다. 지도 시간 변경의 무효화는 해당 질문이 지도 시간에 의존할 때만 적용한다. 예측의 최신 기준은 지도 재생과 독립이다.

- **FR-023 (후속 검증 범위)**: 이전 Kiwi 검증의 92개 불일치를 원 ID/원문/기존 기대·실제 분기와 함께 보존하고, 예상 경로·확정 조건·카드 조건·모호한 의미·실행 금지/대기 조건을 각각 검토 표로 작성한다. 재분류는 AI 작성 초안으로 표시하고 독립 사람 검수 완료로 표현하지 않는다. 현재 라우터·카드 첫 응답과 기존 21,963건을 읽기 전용으로 다시 검사한다. 정답 변경 수와 코드 개선 수를 분리하며 카드 완료율을 자연어 이해 정확도로 세지 않는다. 신규 LLM·실행기 호출 없이 결과와 검토 화면·흐름도를 제공한다.

2026-11-13 사용자 정정: FR-018의 ‘TSP/HCl 잠금 카드 표시’는 철회한다. 비지원 물질의 잠금은 내부 설정으로만 유지하며 카드·토글·잠금 안내·차트 접근성 설명에 TSP/HCl을 노출하지 않는다. 지원 물질 NOx/SOx만 표시하고 원본 보관자료는 유지한다.

- **FR-022 (2026-11-13 후속 승인)**: 고정 초과 빈도 Top 5 칸과 자동 순위 파일 읽기를 제거하고, 기존 질문창에서 기간·전국/지역/사업장 범위·NOx/SOx·집계 방식을 명시적으로 확인한 후 로컬 보관자료를 조회한다. 30분 측정값은 종료시각 기준 `(시작, 종료]`로 계산하고 수치가 원 기준값보다 클 때만 초과다. 0은 유효하고 상태문자/NULL/비양수 기준값은 제외한다. 연속 초과는 정확히 30분 인접한 초과만 묶고, 이전 정상→초과의 확인된 시작·기간 이전부터 지속·결측/앞 기록 부재로 시작 불명인 구간을 구분한다. 결측을 정상으로 보거나 단절 구간을 확정 사건으로 설명하지 않는다. 이 집계는 모델 학습·법적 판정 규칙이 아니다. 질의별 건수·비율·기간·제외/수집 상황·로컬 범위를 표시하고 빈 결과·실패·취소·늦은 응답을 구분한다.

- **질문과 화면 문맥**: 질문 시점, 선택 대상·물질·기간·필터·자료 및 설정 버전.
- **검증된 질의**: 의도, 대상, 시간, 지표, 부등호, 조건 출처, 불확실성, 실행 가능 여부.
- **확인 대화**: 빠진 조건, 선택지, 보존 조건, 질문 당시 문맥. 화면 변경 시 재검증.
- **보관 조회 결과**: 원문·숫자·상태·측정시각·단위/기준 출처 및 실제 대상 범위.
- **참고 계산 결과**: 평균·최댓값·계산/제외 건수·커버리지·원문 출처.
- **화면 명령 결과**: 요청한 변경, 검증 상태, 실제 반영한 값.
- **공식 근거 결과**: 문서·조문·기준일·출처 및 확보하지 않은 적용 범위.

## 성공 기준

### 측정 가능한 결과

- **SC-001**: 확정된 정상 질문 표본에서 대상·물질·기간·지표·부등호와 기대 결과가 100% 일치한다.
- **SC-002**: 원본 F~K 반례 전체에서 확인 전 또는 차단/지원 불가 응답의 데이터·화면 실행 건수가 0이다. 명확한 정정/부정은 전체 조건 검증 후에만 실행한다.
- **SC-003**: 최신·달력·최근 시간 질문과 하루 일부 자료 사례에서 시각 기준·실제 측정시각·미확보 안내 누락이 0건이다.
- **SC-004**: 0·상태문자·NULL 혼합 표본의 평균·최댓값과 계산/제외 건수가 손계산 결과에 모두 일치한다.
- **SC-005**: 같은 자료/설정에서 사업장 방문 순서를 바꿔도 전체 최신 순위가 동일하다.
- **SC-006**: 상태 설정을 바꾼 모든 경계 표본에서 화면과 설명이 동일하며, 수치 부등호·사용자 경고선·원본 기준은 보존된다.
- **SC-007**: 모든 정상·확인·잠금·거절 사례에서 외부 모델 호출·수집 API 호출·원본 변경·외부 연락·설비 제어가 0회다.
- **SC-008**: 기존 두 지도 배경의 선택·드래그·전환 및 그래프·문서 검색 대표 회귀 시나리오가 모두 통과한다.
- **SC-009**: 분기 검증 결과에 원본 182개 질문의 누락이 0이고, LLM/실행기 호출이 0이며, 모든 불일치·생성 방법·미사용 자연어 시험·분기 흐름도를 재현할 수 있다. 이 기준 충족은 라우터의 운영 정확성 완료를 의미하지 않는다.
- **SC-010**: 카드 선택 시험에서 확정된 대상·물질·범위·지표·개수가 모두 보존되고, 만료/문맥 변경/조작된 옵션의 실행이 0회여야 한다. 카드 선택 후의 완료율을 자유 입력의 형태소 이해 정확도와 구분해서 보고한다.

- **FR-025 (영역 분리 비교 실험)**: 고정 질문 진입·이름 후보 검색·자유 문장 해석·공통 조건 검증을 분리하는 접근을 공식 자료와 로컬 명단으로 비교한다. 부분 이름·오타는 자동 확정하지 않고 지역·사업장·굴뚝을 별도 조건으로 유지한다. Kiwi 사용자 사전의 단어 경계 개선, 생성 이름 조각 검색 재현율, 고정 질문 카드 검사 결과를 자연어 의도 정확도와 구분한다. 실사용 빈도가 없는 카드 목록은 제안으로 표시하고 기존 실패 결과를 덮어쓰지 않는다. 이번 단계는 오프라인 실험이며 메인 화면·운영 계약·실제 LLM/실행기를 변경하지 않는다.

## 전제와 의존성

- **2026-11-14 후속 승인**: 제한된 단일/복합 도구 계획은 [305-approved-tool-plans](../305-approved-tool-plans/spec.md)에서 별도 구현한다. 아래 일반 복합 실행 대기는 유지하되 305의 등록 조합에 한해 로컬 계획·조건 카드·합성 결과 상태 검증을 허용한다. 이 변경은 실제 LLM/DB/지도 실행기 연결이 아니다.

- **FR-029 (제한된 자유 표현 확장)**: 실제 Kiwi 조사 표지와 명시 별칭/어미/수량/비교 표현을 정규화해 기존 도구 조건 검증에 연결한다. 등록 대상명은 보호하고 원문과 정규화 내역을 분리한다. 비교·배제·대안·불명확한 시간·지칭은 자동 완료하지 않는다. 관련 도메인 표지만 있는 질문은 범위 밖으로 단정하지 않되 이해 완료로도 보지 않고 해석/확인 후보로 넘긴다. 비용 최적화·원인·예측 등 새 실행 능력을 만들어내지 않는다. 기존 성공 조건의 유지와 확인 강화로 바뀐 기대를 구분하고, 새 원문과 이전 사례의 전후 결과·한계를 공개한다.
- **FR-030 (구어 요청 행위 분리)**: 조회해·조회해서 알려줘 등 명시 요청 행위를 정규화하고 대상·물질·시간·연산·정렬 조건은 별도 검증한다. 정의 질문의 ‘뭐야’와 수치 질문을 구분하며 미지정 연산을 추측하지 않는다. 말투 동치 개발 세트와 수정에 사용하지 않은 새 어순 평가 결과를 구분해 공개한다. FR-029와 동일한 실행 전 경계를 유지한다.
- **FR-031 (의미 관계와 후보 조건 보존)**: 복수 날짜·상충 동작을 마지막 값이나 공통 동작으로 축약하지 않는다. 문서 원문/요약 관계는 모호하면 선택으로 확인한다. 문맥만 있는 요청은 TMS 여부부터 확인하고 그 확인을 명령 이해 완료로 간주하지 않는다. LLM 후보도 자료형·동작/모드별 필드·시각 근거·대상 권한을 동일하게 검증한다. 구형 기대값과 현 사용자 정책이 다른 경우 원본 기대를 덮어쓰지 않고 사례별 검토 근거를 남긴다.

- **FR-028 (페르소나 원문·참고 답변 검토)**: 기업(경영/법규/재무/생산), 환경(분석/지자체/주민/자료검증), 굴뚝관리자(관제/정비/교대/시스템)별 질문과 기대 처리·참고 답변을 결과를 보기 전에 작성한다. 합법적인 비용 절감과 은폐/변조/권한 우회를 구분한다. 측정값·법적 불이익·금액·예측을 만들어 정답으로 삼지 않는다. 기대는 사람 검수 전 초안으로 표시하고, 해석 이관·조건 확인·자동 인식·미지원·차단을 분리한다. 직접 원문과 문법/말투 변형의 결과를 따로 공개하며 원문·기대·실제 분기·불일치·사람 메모를 검토 가능한 파일로 보존한다.

- **FR-027 (원문 명령 의미 보존)**: 도구 분류 외에 대상·물질·시간 기준/구간·범위·비교 부등호/경계·지표·순서·개수·집계 정의를 원문 기대와 비교한다. 상충 조건을 마지막 값으로 덮어써 완료 후보로 올리지 않는다. 누락 조건 카드에서는 기존 확정 조건을 보존한다. 단일 물질 도구에 맞추기 위해 원문의 다중 물질 범위를 줄이면 요청 재작성으로 표시하고 최종 의미 확인을 받는다. 실제 입력창과 엔진의 전 과정을 교차 검증하고 최초 실패·수정·잔여 한계를 공개한다. 실제 LLM/도구 명령은 실행하지 않는다.

- **FR-026 (로컬 실시간 분석 실험실)**: 사용자의 로컬 진행 승인에 따라 기존 관제와 분리한 실험 화면에서 임의 새 질문을 실제 로컬 Kiwi로 분석한다. 등록 질문 카드는 허용 도구 후보만 만들며 대상/물질/시간을 임의 보충하지 않는다. 사업장은 지역·이름·주소 후보를 확인한 뒤 선택하고, 굴뚝은 별도로 명시 선택한다. 자유 문장 해석이 불확실하면 실제 LLM 대신 미연결 안내와 사용자 요청 재작성 경로를 제공한다. 새 질문·취소·늦은 응답·오래된 카드·권한/자료 변경을 검증하고, 완료는 실행 계획까지만 표시한다. 서버는 루프백에만 바인딩하고 자격증명·외부 API·임의 파일/SQL/화면 명령은 받지 않는다. 기존 관제에는 실험실 진입 링크만 추가하며 백업을 보존한다.

- 사용자의 11개 결정이 이번 로컬 기능의 요구 기준이다. 서버·운영 인증·Silver·모델 출력·법령 갱신 계약은 범위 밖의 의존성으로 남긴다.
- 통계는 수집된 숫자 관측의 참고 계산이다. 유효 측정 건수·법정 평균·학습 품질·결측 원인을 확정하지 않는다.
- 전체 보관자료의 이력 집계/순위, 다중 굴뚝 정렬 비교, 자유로운 복합 작업, LLM 대체 해석, 새 예측, SOP 권고는 이번 첫 실행기 범위 밖이다. 인식하더라도 이유와 함께 지원 불가로 처리한다.
- 공식 근거 검색은 302를 재사용한다. 원본 문서의 기준일·시행본 검증은 새로 충족한 것으로 간주하지 않는다.
- 이번 산출물은 명세·계획·작업 목록이며 코드 구현·운영 배포 완료를 의미하지 않는다.
