## 사용 방법

**이 문서는 옛 코드를 옮기는 지침이 아니라, 새로 만들 화면의 구현 지시서(브리프)다.** 새 코드는 디자인(§2), 기능(§3), 구조(§4), 서버 약속(§5), 순서(§6)를 보고 새로 쓴다. 옛 코드에서는 **화면과 무관한 순수 로직만** 가져온다(§4). 옛 코드에 숨어 있는 규칙(상태 분류, 숫자 표시, 공백 처리, 물질 잠금, 안내 문구)은 새로 쓸 때 놓치기 쉬우므로, 각 단계를 시작할 때 해당 옛 파일을 읽어 **규칙을 이 문서의 §10에 옮겨 적고 시험으로 고정한다.** 같은 데이터에서 같은 숫자가 나오는지가 완료 기준이다.

- **Access 토큰**은 `auth.user.access_token`으로 바로 꺼낼 수 있다(중간 프론트의 `TmsAuth`에서 못 찾던 문제가 없다). 에이전트 호출에 그대로 쓴다.

## 3. 옮길 기능 (재영 님 정리 반영)

**화면 구성**
- 상단바: **일단 비운다.**
- 좌측 레일: 통합 관제 / 경고 목록(개수 배지) / 측정 추세 / 라이트·다크 전환
- 머리말: 제목, 화면 기준 시각(예: 11.02 14:30)
- 지표 카드 **4개**: 주의·경고·위험·초과
- 섹션 01 우선 확인 지역: 지도 패널(경로 표시, 상태 필터, 캔버스, 툴팁, 방위, 이동 버튼 뒤로·상위로·전국, 캡션) + 우선 확인 목록(건수 배지, 사업장명·주소·코드 검색, 맥락 문구, 경고 목록)
- 섹션 02 선택 굴뚝 분석: 차트 패널(위치·제목, 물질 NOx·SOx, 기간 6·12·24시간, 30분 측정 안내, 판독 문구, 추세 차트, 툴팁, **데이터 공백 설명**, 범례, 측정값 표 열기/닫기) + 우측 상세 패널
- 푸터: 상태 분류 기준(≥70·80·90·100), 접근성(건너뛰기 링크, `aria-live`)

**지도**: 전국→시도→시군→사업장 내려가기와 상위로 이동, 자유 이동(선택해도 한 지역에 갇히지 않음), 네이버 지도 전환, 마커 움직임(표현만, 값은 보간하지 않음), 방위, 지형·등고선, **최신 1일치(48시점, 30분)의 흐름만** 보여 주는 지도 시계(과거 날짜를 넘겨 보는 기능은 두지 않는다. 예측값은 만들지 않음), 지도 ↔ 목록 선택 연동

**차트·분석**: 단일·다중 차트, 조회 범위, 확대·포커스, 경고 민감도 패널(표시 민감도만 바꾸고 원본 기준은 안 바꿈), 물질 잠금(NOx·SOx 2종), 선택 사업장 일별 이력
- **새 요구: 차트를 클릭하면 그 시점의 수치를 보여 준다.** 기본은 지금처럼 가장 오른쪽(최신) 값이고, 클릭하면 그 시점으로 옮겨 간다.
- **굴뚝의 이력은 하단 차트가 상세하게 맡는다**(지도는 최신 1일치만 보여 준다). 기간은 6·12·24시간에서 시작하고, RDS에 쌓인 날짜만큼 일 단위로 넓힌다.
- **예측과 설명을 차트에 얹는다**(E의 예측 결과와 설명이 정해진 뒤). "왜 초과를 예측했나"를 물을 때 관측선 위에 예측 구간(점선)과 근거를 이어서 보여 주려는 것이다. 지금은 이 레이어가 들어갈 자리와 데이터 모양만 비워 둔다.

**개인 기능**: Cognito 로그인·로그아웃(이미 A가 구현), 즐겨찾기 사업장, 알림 설정(**"임시" 표기 제거**), 공지 롤링 배너(즐겨찾기 굴뚝의 경고·위험·초과)

**에이전트 창(결정 2026-11-20, D · 구현 `src/agent/`)**: 우하단 열기 버튼 → 사이드 창 → 전체 창 전환. **자유 이동**(머리의 빈 곳이나 왼쪽 위 손잡이를 끌어 어디로든, 방향키 16px·Shift 64px, 더블클릭·Home은 원래 자리), **자유 크기 조절**(가장자리 4곳 + 모서리 4곳, 폭·**높이 모두**, 최소 320×240, 최대 폭=화면-32px·높이=화면 전체, 방향키 미세 조절, 가장자리 더블클릭은 그 방향만 기본 크기 — 옛 웹은 좌우 폭만 가능했다). 위치·크기·모드는 이 브라우저에만 저장하고(옛 웹과 같은 키 `tms-agent-frame-rect`·`-mode`) 화면이 줄면 안으로 끌어 넣는다. **폭 640px 이하는 이동·크기 조절 없이 전체 시트**, 전체 모드에서도 없다. Esc는 전체 → 사이드 → 닫기. 위치·크기·마스코트 이동 계산은 옛 웹의 순수 로직(`agent-frame-geometry.js`·`mascot-engine.js`)을 TypeScript로 옮기고 옛 시험도 그대로 옮겼다. **채팅 연결(`/agent/chat`)은 아직 없다**(입력은 화면에만 남고 "아직 연결되지 않았습니다" 안내, ⑤단계).
- **마스코트(화면 돌아다니기, 옛 웹의 마스코트 복원)**: 열기 버튼 자체가 화면 가장자리(바닥·벽·천장)를 돌아다니는 캐릭터다. 누르면(거의 안 움직이면) 창을 열고, 끌면 잡아 옮기며 놓으면 던져져 떨어져 바닥에 내려앉는다. 창이 열려 있는 동안은 숨고 닫으면 우하단에서 다시 나타난다. **기본은 꺼짐**(옛 웹과 같음): **창 머리(제목 줄)의 "돌아다니기" 스위치**(한 줄을 따로 차지하지 않고, 설명은 마우스를 올리면 보인다, 저장 `tms-mascot=on`)나 주소 `?mascot=on`으로 켜고 `?mascot=off`가 가장 우선이다. **540px 이하 좁은 화면은 항상 고정 버튼**, **움직임 줄이기 설정이면 제자리에서 클릭만** 받는다. 탭이 숨으면 멈추고 돌아오면 이어서 움직인다. 이미지는 A의 `public/mascot.png`(같은 캐릭터)이고, 위치는 React 상태가 아니라 DOM을 직접 갱신한다.

## 4. 구조 (세 층)

```
        ┌────────── 선택 상태(Zustand 스토어) ──────────┐
        │ 선택 사업장·굴뚝 · 물질 · 기간 · 지도 단계    │
        │ 필터 · 검색어 · 즐겨찾기                      │
        └──▲────────▲────────▲────────▲────────▲────────┘
          지도     목록     차트   에이전트 창  공지 배너
          (읽고, 누르면 스토어에 "선택해라"라고 한 번만 쓴다)
                     ▲
              데이터 훅(useSites, useSeries …) — 정적 JSON → API로 바꿀 때 이 층만 교체
```

- **스토어에는 사용자가 고른 것만** 넣는다. **측정값은 넣지 않는다**(선택으로부터 데이터 훅이 가져온다).
- **시간은 둘로 나눈다.** 지도 시계(최신 1일 안의 시점)는 지도가 갖고, 차트에서 클릭한 시점(이력 안의 시점)은 차트가 갖는다. 서로 영향을 주지 않는다.
- 컴포넌트는 서로를 부르지 않는다. 읽기(값이 바뀌면 자동 갱신)와 쓰기(선택 변경)만 한다.
- 폴더(제안): `src/state/`(스토어), `src/data/`(훅), `src/theme/`(색 변수·테마), `src/components/{map,list,chart,agent,notice}`, `src/logic/`(재사용 순수 로직)

**새로 만드는 것 / 재사용하는 것**

| 대상 | 방식 |
|---|---|
| 지역 지도 | **새로 만든다. 점·선이 많으므로 연산 부하가 가장 적은 방식(아래 "지도 성능 원칙")**. 점·선 하나하나를 React 컴포넌트나 SVG 요소로 만들지 않는다. 좌표 변환·확대 계산 같은 순수 함수만 재사용 |
| 네이버 지도 | **감싼다**. 지도 종류 선택(관제 / 네이버 일반 / 네이버 위성)으로 전환하고, 네이버 모드에서는 이동·확대를 네이버가 맡고 **투명한 캔버스를 그 위에 겹쳐** 핀·묶음·선택 화살표를 기존 코드로 그린다(아래 "네이버 지도 전환"). 구현은 `src/map/naver/` |
| 추세 차트 | **새로 만든다.** A의 `LiveChart`처럼 직접 그린 SVG, 그라데이션 영역 |
| 순수 로직 | 재사용: `mascot-engine`, `agent-frame-geometry`, `notice-banner-core`, `map-time-model`, `data-model`(이미 DOM 없이 시험됨). 시험(`tests/*.test.mjs`)도 같이 옮긴다 |
| 화면(HTML·CSS) | 전부 새로 만든다(디자인이 바뀌므로) |

### 지도 성능 원칙 (결정 2026-11-20, D: "점과 선분이 많아서 걱정, 연산 부하가 가장 적은 방식")

③ 단계를 시작하기 전에 실제 점·선 개수를 세어(경계선 꼭짓점 수, 사업장·굴뚝 수) 아래 예산을 확정한다. 방식은 이렇다.

1. **그리기는 Canvas 2D 한 장**. 경계선·지형선·마커를 DOM 노드로 만들지 않는다(노드가 수천 개가 되면 React 비교와 브라우저 배치가 병목). 마커 수가 많아져도 그리기 호출만 늘고 DOM은 그대로다.
2. **경계 데이터는 미리 줄여 둔다**. 빌드 때 확대 단계(전국·시도·시군)별로 꼭짓점을 단순화(Douglas–Peucker 계열)하고 정수 좌표 배열로 저장한다. 화면에는 그 단계의 것만 올린다. 브라우저에서 단순화 계산을 하지 않는다.
3. **다시 그릴 때만 그린다**. 선택·확대·이동·시점 변경이 있을 때만 `requestAnimationFrame`으로 한 번 그리고, 가만히 있으면 아무 일도 하지 않는다. 경계 같은 정지 레이어는 오프스크린 캔버스에 한 번 그려 두고 이동·확대 때 그 이미지를 옮긴다.
4. **선택·마우스 올림은 공간 색인으로 찾는다**. 마커는 격자(또는 `Float32Array` + 격자 버킷)로 가까운 후보만 검사한다. 전부 순회하지 않는다.
5. **전국 단계에서는 묶어 보인다**(군집). 줄여서 보이는 것이므로 개수·최고 단계를 함께 표기하고, 값은 합치거나 평균내지 않는다. 최고 단계만 보여 준다.
6. **React는 틀만 맡는다**. 캔버스는 `useRef` + 효과 안에서 그리고, 마커 위치·단계는 스토어에서 읽은 데이터 배열을 그대로 넘긴다. 마커마다 상태를 갖지 않는다.
7. **마커 움직임은 표현만**(§10, 값 보간 없음). 움직이는 마커 수에 상한을 두고, 탭이 가려지면(`document.hidden`) 멈춘다.
8. **목록은 가상화**한다. 화면에 보이는 줄만 렌더한다.
9. **접근성**: 캔버스는 시각용이므로 같은 선택·정보는 목록과 키보드로 접근할 수 있어야 한다(목록이 대체 수단).
10. **시험**: 단순화·좌표 변환·공간 색인(가장 가까운 마커)은 순수 함수로 두고 단위 시험한다. 성능은 대표 데이터로 그리기 시간을 재서 예산(기본 한 프레임 16ms 이내)을 넘으면 실패로 본다.

네이버 지도는 외부 SDK가 직접 그리므로 이 원칙 밖이다(감싸기만).

### 네이버 지도 전환 (옛 지도 `map-engine-switchable.js`·`map-engine-naver.js`에서 옮김, 2026-11-20)

- **선택**: 지도 윗줄 오른쪽 묶음(상태 칩 앞)에 `관제 | 일반 | 위성` 한 줄(줄을 늘리지 않음). 기본은 관제 지도(Canvas). 한 번에 한 모드만 있다. 고른 모드는 이 브라우저의 `tms-map-mode`에 저장하고(저장소를 못 써도 동작) 다음에 열 때 복원한다. 선택한 사업장·시각·상태 칩은 모드를 바꿔도 그대로다.
- **SDK 읽기**: 네이버를 처음 고를 때 한 번만 읽는다(처음 화면 로딩을 늘리지 않음). `https://oapi.map.naver.com/openapi/v3/maps.js?ncpKeyId=<ID>`, 20초 안에 안 되면 시간 초과, 스크립트 오류·SDK가 비어 있음·인증 실패(`navermap_authFailure`, 읽는 도중이든 읽은 뒤든)는 모두 **이유를 지도 위에 안내하고 관제 지도를 계속 쓴다**. 동시에 여러 번 불러도 한 번만 읽고, 실패하면 다음 선택 때 다시 시도한다(인증 실패는 같은 화면에서 반복해도 소용없어 막는다). 값이 빈 문자열이면 SDK를 부르지 않고 안내한다.
- **키(결정 2026-11-20, 사용자): 공개 앱 ID라 저장소에 둔다.** 네이버 Client ID는 브라우저에 노출되는 값이고(Client Secret 아님, 옛 설정 파일에도 소유자가 공개를 명시) 보호는 값이 아니라 **네이버 클라우드 콘솔의 Web 서비스 URL(등록 도메인)**이 한다. 기본값은 `src/map/naver/config.ts`에 두고, 환경 변수 `VITE_NAVER_MAP_KEY_ID`는 덮어쓰기용이다(배포 설정에 추가할 필요 없음). 인증이 통과하려면 콘솔 Web 서비스 URL에 `http://localhost:5173`과 운영 도메인(`https://smokestack-guard.store`)이 등록돼 있어야 한다. 안내 문구는 "허용된 도메인인지 확인".
- **그리는 방식**: 네이버가 땅·길·위성을 그린다. 우리는 **투명한 캔버스 한 장**을 지도 위에 겹쳐 기존 핀·묶음·수면 파형·번쩍임·선택 화살표 코드를 그대로 쓴다. **네이버 모드에서는 땅·등고선·경계를 그리지 않는다**(등고선 버튼도 숨김). 캔버스는 마우스 조작을 지도에 넘기고(`pointer-events: none`), 올림·클릭·오른쪽 클릭·마우스 벗어남은 네이버 지도 이벤트로 받아 같은 판정(`pinHit`)에 넣는다. 네이버 로고·저작권 표기는 끄지 않는다.
- **좌표 맞추기**: 보이는 범위(View)는 확대 수식이 아니라 **네이버 투영에서 기준 두 점의 화면 위치를 재서** 만든다(타일 기준이 다르거나 확대 도중의 소수 줌이어도 핀이 어긋나지 않음). 끌거나 확대하는 중에는 직전 묶음을 따라 옮겨 그리고, 멈추면(`idle`) 다시 묶는다. 멈춘 범위를 `setMapBounds`로 알려 경고 목록이 "지도에 보이는 사업장"을 거른다.
- **이동 규칙(옛 어댑터와 같음)**: 확대 6~18(정수), 한국 범위 제한(남서 31.5·123, 북동 40·133), 처음 중심 36·127.7·확대 7. **사업장을 고르면 확대 15까지** `morph`로 부드럽게 들어간다(이미 15 이상이고 화면 여백 안이면 가만히 둔다). 묶음 누르기는 정수 확대 단위로 한 단계 이상 더 들어간다(구성원이 잘리지 않게 내림), 전국 보기는 내림(다 보이게). 확대 한도에서도 안 갈라지는 묶음은 같은 "고르기 목록"이다.

### 옛 지도에서 옮긴 지도 규칙 (③ 구현, 2026-11-20)

- **투영**: 웹 메르카토르 세계 좌표(세계 폭 256). 축척은 "세계 1칸이 몇 px인지"이고 한도는 20~4096이다. 옛 등고선 파일이 이 좌표라서 경계·사업장·등고선이 같은 좌표계를 쓴다.
- **단계**: 축척 180 미만 전국, 180~700 지역, 700 이상 사업장.
- **묶기**: 화면 거리 기준, 반경 전국 100px·그 밖 86px. 묶음끼리는 서로 반경 이상 떨어질 때까지 합친다. **끌어서 움직이는 동안은 다시 묶지 않고 직전 묶음을 따라 옮겨 그리며, 놓으면 새로 묶는다**(등고선과 같은 시점, 휠 확대는 멈춘 뒤 0.16초). 묶음을 누르면 구성원이 풀려 보이도록 확대한다(경로는 바꾸지 않는다: 선택해도 한 지역에 갇히지 않음). 묶음의 대표 단계는 구성원 중 가장 높은 단계이고 공백은 단계를 가리지 않는다.
- **마커(굴뚝 표시)**: 옛 지도의 모양 — 땅 위의 타원 후광 + 위로 솟는 빛기둥(아래가 진하고 위로 투명) + 바닥 받침 + 개수 배지(묶음일 때만). 받침이 사업장의 실제 위치다. 단계는 색과 **빛기둥 높이**로 같이 나타낸다(주의 26·경고 33·위험 40·초과 48px, 정상·공백은 기둥 없이 받침만). 선택하면 후광이 굵은 강조색이 된다.
- **지도 시계**: **보여 주기만 한다(조작 없음)**. 12시간 아날로그(시침·분침 모두 화살표, 오전/오후 표기) + 날짜·시각 **플립 숫자판**(값이 바뀔 때 넘어감, 처음 그릴 때와 모션 감소 설정에서는 움직이지 않음). 접으면 작은 버튼이 된다. **재생 중에는 바늘이 "다음 칸"을 향해 한 칸 간격 동안 일정한 속도로 돌아**(숫자판이 넘어가는 순간 바늘이 그 시각에 닿는다) 재생 속도에 맞는다. 멈추거나 슬라이더로 뛸 때는 0.25초로 옮겨 간다. 0도를 넘을 때 거꾸로 한 바퀴 돌지 않게 누적 각도를 쓴다.
- **재생 조작**은 지도 아래 한 줄: `▶/⏸` + 배속(0.5×·1×·2×·4× = 칸당 3.2·1.6·0.8·0.4초, 누를 때마다 바뀜) + 슬라이더 + 시각 + 최신. 끝에 닿는 순간 멈추고, 끝에서 누르면 처음부터. 슬라이더·최신을 누르면 재생이 멈춘다.
- **마우스를 올리면(옛 지도와 같음)**: 굴뚝 표시에 조명이 켜지고(번짐) 후광에서 **수면 파형**(타원 고리 두 겹, 1.8초 주기)이 퍼진다. **새로 경고가 된 굴뚝**(시각이 한두 칸 바뀌며 주의 이상이 되었거나 단계가 오른 것)은 **묶음 기준으로** 한 번 번쩍이며 고리가 퍼진다(0.7초): 넓게 보면 그 굴뚝이 든 묶음 하나가, 확대해서 풀리면 그 굴뚝이 번쩍인다. 개수 상한은 두지 않는다. 슬라이더로 크게 뛰면 번쩍이지 않는다. 모션 감소 설정에서는 움직이지 않는다. 애니메이션이 있을 때만 프레임을 부르고, 땅·등고선은 한 번 그려 둔 그림을 재사용한다.
- **선택 표시**: **노란 아래 화살표의 꼭지가 선택한 사업장의 실제 좌표**를 가리킨다(묶음과 상관없음). 초록 원은 쓰지 않는다. **선택한 사업장을 다시 누르면(지도 핀·목록 모두) 해제**되고, **지도에서 오른쪽 클릭해도 해제**된다(브라우저 메뉴는 띄우지 않음).
- **움직이는 동안의 바닥 그림(관제 지도, 2026-11-20)**: 멈춘 상태에서 땅·등고선·경계를 화면보다 사방 50% 큰 한 장으로 그려 두고, 끌거나 확대하는 동안에는 새로 그리지 않고 그 그림을 옮기고 늘려서 쓴다(등고선도 같이 움직인다). 멈추면 새 보기로 선명하게 다시 그린다. 그림이 화면을 다 덮지 못하거나 배율이 0.55~2배를 벗어나면 그때만 지금 보기로 다시 그리고(등고선 없이), 멈추면 등고선까지 다시 그린다. 네이버 모드는 바닥을 그리지 않는다(네이버가 그린다).
- **네이버 모드의 핀(2026-11-20)**: 네이버 `fromCoordToOffset`은 지도 판 기준이라 현재 중심이 화면 가운데가 되도록 보정해 View를 만든다. 끄는 동안은 매 프레임 따라가고, 휠·더블클릭 확대와 코드가 시작한 이동(묶음 확대·사업장 선택·전국 보기)에서는 핀을 숨겼다가 멈추면(최대 0.8초) 다시 그린다(이전 네이버 지도와 같음).
- **자유 이동(옛 지도와 같음)**: 지역을 눌러서 세부 지역으로 가는 기능은 **없다**(결정 2026-11-20, D). 빈 땅을 눌러도 아무 일도 일어나지 않는다. 지도는 다른 사업장을 숨기거나 흐리게 하지 않는다. **지역(경로)은 확대·이동을 멈춘 뒤 화면 중앙을 보고 판단한다**: 광역(축척 180 미만)에서는 특정하지 않고, 180 이상에서 중앙이 든 시도 경계(바다면 150px 안의 가까운 사업장으로 짐작), 450 이상(상세)에서 중앙에서 120px 안의 가장 가까운 사업장의 시군까지. 이 경로는 **지도를 움직이지 않고** 지도 위쪽 위치 표시("지도 중앙 › 서울 › 중구")만 채운다(경고 목록은 이 경로가 아니라 지도에 보이는 범위로 거른다, 아래 "경고 목록의 기준"). 위치 표시는 읽기 전용이다(시군 칩·상위로 버튼은 없다). "전국 보기" 버튼은 처음 전체 화면으로 부드럽게 돌아간다.
- **지도 윗줄(한 줄)**: 왼쪽에 `지도` 제목 · `지도 중앙 › 전국/시도/시군`(읽기 전용), **오른쪽(등고선 쪽)에 `정상 주의 경고 위험 초과 공백` 상태 칩 · `등고선 켬/끔` · `전국 보기`**를 모은다(좁으면 줄바꿈). 상태 칩은 **지도에 그릴 상태**를 켜고 끈다(처음엔 모두 켬). 끈 상태의 굴뚝은 그리지 않고 묶음 계산에서도 빠지므로 묶음의 개수·대표 단계는 보이는 것만 센다. **공백**은 측정값이 없는 굴뚝이다(값 칸이 미수신·기기점검·가동중지·보수중·측정자료확인중 같은 문구이거나 비어 있음. 보관 하루치 기준 측정 칸의 약 1/3이 공백이고 그중 미수신은 9,669칸). 경고 목록의 단계 필터와는 따로다.
- **쭉쭉 확대**: 이동은 모두 부드럽게 넘어간다(중심은 직선·배율은 비율로, 배율 차이가 클수록 450~900ms). **사업장을 고르면(핀·목록)** 그 사업장이 가운데 오도록 **최대 상세(축척 1600)까지 확대**해 들어간다(이미 1600 이상이고 화면 여백 안이면 가만히 둔다). **묶음을 누르면** 구성원 쪽으로 **한 번에 최소 2배** 확대하고(구성원이 다 보이면 그 범위까지) 누를수록 풀려 결국 사업장 하나가 된다. 사용자가 끌거나 휠을 돌리면 자동 이동은 멈춘다. 화면 크기가 바뀌어도 보던 곳을 유지한다.
- **붙어 있는 사업장 풀기**: 산업단지에는 옛 확대 한도(축척 4096, 1px≈29m)에서도 30px 안에 붙은 사업장이 많아(실측 722쌍) 묶음이 풀리지 않았다. 그래서 ① **확대 한도를 32768(1px≈3.6m)로 8배 늘리고**, ② 최대 상세(1400) 이후에는 묶음 반경을 60px에서 **깊이 들어갈수록 줄여 26px까지** 내리며, ③ 그래도 안 갈라지는 묶음(한도에서도 26px 안, 곧 좌표가 사실상 같음)이나 이미 한도인 묶음을 누르면 **"같은 자리 N곳 · 하나를 고르세요" 목록**을 그 자리에 띄운다(단계 높은 순, 사업장명·비율). 고르면 선택되고 닫힌다. 목록은 Esc·오른쪽 클릭·지도 조작(끌기·휠)·선택 변경으로 닫힌다. 말풍선은 풀리는 묶음에는 "눌러서 확대", 안 풀리는 묶음에는 "눌러서 고르기"로 안내한다. 사업장 위치는 깊이 확대에서도 흔들리지 않게 64비트로 둔다.
- **선택하면 그래프로 밀어 주기**: 사업장을 고르면(핀·목록·고르기 목록, 노란 화살표가 뜰 때) **바로 아래 굴뚝 그래프 구역으로 화면을 부드럽게 민다**(모션 감소 설정이면 즉시). 해제할 때는 밀지 않고, 다른 사업장을 고르면 다시 민다. 맨 위로는 왼쪽 레일의 통합 관제 버튼으로 돌아간다.
- **경고 목록의 기준(결정 2026-11-20, D · 지도 중앙 지역 기준을 폐기)**: 목록은 두 모드다. **① 검색어가 없을 때: 지금 지도에 보이는 경고만** — 주의 이상(주의·경고·위험·초과) 사업장 중 **지도 화면 안에 있고**(이동·확대를 멈춘 뒤의 보이는 범위) **지도의 상태 칩에서 켜 둔 상태**인 것. 지도를 옮기면 목록이 따라 바뀌고, 칩에서 끈 상태는 목록에서도 빠진다. **② 검색어가 있을 때: 전국 검색** — 지도 범위·지도 칩과 상관없이 이름·주소·코드로 찾고, **정상·공백 사업장도 찾는다**(골라 보면 지도가 그 사업장으로 이동). 검색어를 지우면 ①로 돌아온다. 윗줄에 "N곳 · 지금 지도에 보이는 경고 / 전국 검색 결과"를 적고, 지도에 보이는 경고가 없으면 지도를 움직이거나 검색하라고 안내한다. 정렬은 모드와 무관하게 ① 즐겨찾기 ② 단계 높은 순(경고가 위, 정상·공백이 아래) ③ 같은 단계는 기준 대비 비율 높은 순이고, 목록 자체의 단계 필터(주의~초과)는 두 모드 모두에 적용된다. 시각이 바뀌거나(재생 포함) 지도를 멈출 때 갱신된다. 지도의 "지도 중앙 › 시도·시군" 표시는 위치 안내일 뿐 목록을 거르지 않는다.
- **클릭 범위와 실수 방지**: 핀은 **후광·빛기둥·개수 배지 전체(+여유 8px)**를 누를 수 있다(점 하나를 정확히 누르지 않아도 됨). 마우스를 올렸을 때 반응하는 범위도 같다. 같은 핀을 350ms 안에 다시 누르는 것(더블클릭의 두 번째)은 선택 토글로 치지 않는다.
- **칸 배치**: 지도와 경고 목록 칸의 **높이는 지도 칸이 정한다**(화면 높이의 91%, 624~988px 고정 — 이전 크기의 1.3배). 경고 목록이 길거나 짧아도 지도가 커지거나 작아지지 않고, 목록은 그 높이에 맞춰 안에서 스크롤한다. 좁은 화면(980px 이하)에서는 지도 600px·목록 600px을 세로로 쌓는다.
- **재생 중 보기 유지**: 시각이 바뀌어도(재생 포함) 지도의 위치·확대는 그대로다. (결함 기록: 보기 맞추기 효과가 칸마다 새로 만든 목록에 걸려 있어 재생 때 전체 화면으로 되돌아갔다. 경로가 바뀔 때만 맞추도록 고치고 회귀 시험을 둠.)
- **확대 등급 4단계**(축척 기준 0 광역 <180 · 1 간략 180~450 · 2 상세 450~1400 · 3 최대 상세 ≥1400). 묶음 반경이 100→86→72→60px로 줄고, 등고선은 아래처럼 단계별로 늘어난다. 처음 로딩을 줄이는 것이 목적이라 넓게 볼 때는 큰 파일을 읽지 않는다. 녹색 음영은 쓰지 않는다(결정 2026-11-20, D).

  | 등급 | 읽는 파일 | 그리는 것 |
  |---|---|---|
  | 0 광역 | 개요(800m 간격, 0.1MB) | 가장 성긴 큰 능선선만, 아주 은은하게 |
  | 1 간략 | 개요 | 큰 능선선만 |
  | 2 상세 | 화면과 겹치는 시도 파일(200m 간격, 시도당 0.1~0.7MB) | 굵은 선 + 흐린 얇은 선 |
  | 3 최대 상세 | 같음 | 모든 선이 뚜렷 |

  굵은 선은 400m의 배수, 나머지는 얇은 선이다. 보유 자료의 간격(개요 800m·지역 200m)이 한계라 100m·50m·10m 간격의 선은 만들 수 없다(필요하면 지형 타일에서 새로 만들어야 한다). 등고선 목록·개요 파일은 첫 화면이 그려진 뒤 브라우저가 한가할 때 읽는다.
- **등고선 색**: 고도 색상표로 높이와 색이 일대일로 맞되 **채도를 낮춘 차분한 색조**(0m 회녹색 → 200 연한 녹색 → 400 올리브 → 600 모래빛 → 800 연갈색 → 1000 흙빛 → 1400 적갈색 → 1800m 이상 옅은 회백색)다. 높을수록 조금 더 진하고 굵다(농도는 0.18~0.5 범위, 중간 고도의 노란 기운은 특히 연하게). 낮은 곳부터 그려 높은 곳이 위에 온다.
- **휠**: 지도 안에서만 확대하고 페이지 스크롤로 새지 않는다.
- **차트 수치는 상대 수치(%)만(결정 2026-11-20, D)**: 화면 어디에도 **ppm 같은 절대 수치를 쓰지 않는다**(값 표시·세로 눈금·기준값·상세 패널 모두). 모든 수치는 **기준 대비 비율(%)**이고 **단일 물질이어도 %**다. 세로 눈금은 `0% · 100% · 위쪽 한계(기본 120%)`다. 기준값이 없는 물질은 비율을 알 수 없어 그래프에 그리지 않고 카드에 "기준값 없음"으로 알린다(켤 수 없음). 비율 표기는 10% 이상 정수, 그 아래는 소수 한 자리.
- **차트 물질 선택 = 큰 체크 상자(카드)**(옛 웹의 물질 카드): `NOx` `SOx` 카드마다 큰 체크 상자(32px)와 물질 이름·`표시 켬/끔`, 그리고 **안에 선택한 시점의 기준 대비 %(34px)와 단계**를 보여 준다. 꺼 둔 물질의 카드에도 값이 보인다(켜기 전에 확인). **둘 다 켤 수 있고 둘 다 끌 수도 있다**(둘 다 끄면 그래프 자리에 "물질을 하나 이상 켜면 그래프가 나옵니다" 안내). 그래프에서는 모양으로도 구분한다(NOx 원·초록, SOx 사각형·파랑). 두 물질은 각자 기준 대비 %로 **같은 눈금**에 그리고(같은 비율은 같은 높이, 위쪽 한계는 큰 쪽에 맞춰 공통으로 늘어남), 값 표시는 시점을 바꾸면 두 카드가 함께 바뀐다. 빈 구간 점선·칠은 물질별 자기 색이다. **한 물질만 측정하는 굴뚝(NOx만 또는 SOx만, 2026-11-20)은 체크 상자를 없애고** "물질 이름 · 단일 측정 · 기준 대비 % · 단계" 한 줄만 보여 주며, 선택 상태와 관계없이 그 물질을 늘 그린다. 두 물질이 모두 측정되는 굴뚝만 상자를 둔다.
- **글자 크기(깨알 같다는 의견 반영 · 결정 2026-11-20, D)**: 화면의 글자를 크게 키운다. **본문·버튼·목록 13px 이상**(이전 10~13px → 13~19px), **차트 안 글자(눈금·기준선 이름)는 사용자 단위 16**(SVG는 화면에서 줄어들어 이전 11은 실제 약 9px였다), 지도 시계 숫자 15·설명 13, 지도 개수 배지 17px. 시험(`fontSize.test.ts`)이 스타일 파일에서 13px 아래 글자가 다시 생기면 실패하게 한다. A의 첫 화면(landing.css)은 이 범위가 아니다.
- **차트 조회 범위(옛 웹의 조회 범위 · 결정 2026-11-20, D)**: **시작·종료 일시를 달력(`datetime-local`, 30분 단위, 한국 시각)으로 고르고 `조회 적용`**을 누른다. 고를 수 있는 날짜는 **보관된 기간 안**으로 제한된다(달력 min/max, 입력은 직접 검증해 이유를 알림: 종료가 시작보다 뒤여야 함·보관된 기간 밖·그 사이 보관된 측정 없음, 걸치면 보관된 기간 안으로 줄여 받음). `← 이전 구간` `다음 구간 →`은 **창에 든 칸 수만큼** 넘기고(한 점이 두 구간에 겹치지 않음) 자료 끝에서 멈춘다. **슬라이더**로 구간을 30분 단위로 밀고(창이 자료 전체면 비활성), **그래프를 좌우로 끌면 30분씩 이동**한다(끌고 놓은 뒤의 클릭은 시점 선택이 아님). `자료 기준으로`는 지정한 범위를 지우고, **기간 버튼(6·12·24시간, 자료가 채우면 2일·3일…)은 누르면 지정한 범위를 지우고** 그 길이의 기본 범위(마지막에서 거슬러 올라감)가 된다. 요약 줄에 "기본 범위/사용자 지정 · 시작 → 끝 · 길이"를 보인다. 지정한 범위는 사업장·굴뚝·물질을 바꿔도 유지된다(같은 시간대 비교). 범위는 보여 주는 창일 뿐 없는 측정을 만들거나 수집을 일으키지 않는다. 지금 개발 데이터는 하루치(48칸)라 달력은 그 하루만 고를 수 있고 슬라이더·이전/다음은 6·12시간 창에서만 움직인다. 여러 날은 RDS 쌓인 날짜만큼 같은 화면에서 넓어진다(데이터 훅이 더 긴 시점 배열을 주면 됨).
- **차트 세로 눈금(결정 2026-11-20, D)**: 기준값(100%) **아래는 그림 높이의 80%에 고정**하고(0~100%, 주의·경고·위험·초과 기준선은 이 안에 있다), **위쪽 20%는 "기준 초과 영역"**이다. 이 영역은 **120%까지가 기본**이고 값이 120%를 넘을 때만 위쪽 한계가 10% 단위로 늘어난다(5% 여유). 기준을 크게 넘어도 아래쪽 80%의 모양은 변하지 않아 선이 뾰족해지지 않는다. 위쪽은 압축 표시이므로 눈금 글자에 기준값과 위쪽 한계 값을 적고 구역에 "기준 초과 영역(압축)"이라 표기한다. 기준값이 없는 굴뚝은 단계를 알 수 없어 선형 눈금이고 위쪽 영역이 없다.
- **차트의 값 없는 구간**: 0으로 채우지 않는다. **값이 없는 구간은 모두(앞·가운데·뒤) 점선으로 잇고, 그 점선 아래만 옅게 칠한다**(점선 위로는 칠하지 않는다). 가운데는 양쪽 실측 사이를 잇고, 첫 실측 앞은 첫 값 높이로, 마지막 실측 뒤는 마지막 값 높이로 끝까지 잇는다(추정선, 측정값 아님). 칠은 모든 종류가 같다(위 0.2 → 아래 0.05의 옅은 그라데이션). 차트 전체 높이를 덮는 회색 띠는 쓰지 않는다. 실측이 하나도 없는 기간만 이을 점선이 없어 기간 전체를 옅게 칠한다. 칠한 영역에 올리면 사유(미수신·기기점검 등)를 안내하고, 최신 값 표시는 계속 "측정 공백"이다.
- **굴뚝이 많은 사업장**: 굴뚝이 10개를 넘으면 차트의 굴뚝 선택을 줄 대신 번호 검색으로 한다(실측 기준 10개 초과 사업장 42곳, 최대 234개).
- **배포 보류**: 등고선(약 5.6MB)·경계 데이터를 운영에 어떻게 올릴지(정적 파일 vs 별도 경로)는 A와 정한다. 지금은 개발 서버 전용(`dev-data/`, git 제외)이다.


## 5. 에이전트 연결 규약 (`POST {API_BASE}/agent/chat`)

- 헤더 `Authorization: Bearer <auth.user.access_token>`.
- 요청: `{conversation_id?, message}` 또는 `{conversation_id, resume:{card_id, option_id}}`, 선택 `context:{selectedStackId}`(필드는 이 셋뿐, 그 밖은 422).
- 응답: `status`(`ANSWERED`·`NEEDS_INPUT`·`PARTIAL`·`REFUSED`), `parts[]`(답·숫자·안내), `card`(옵션 선택 → `resume`으로 재호출), `notices[]`, `data_as_of`. 카드 종류: `STACK_CANDIDATES`, `STACK_CODE`, `POLLUTANT`, `TIME`, `OPERATION`, `CHOOSE_PART`, `MAP_OR_RETYPE`, `SCOPE`, `PERIOD`.
- 오류: `401`(재로그인), **`403 {detail:{code:"not_member"}}`**(초대 코드 전: A의 `Invite` 화면으로 보낸다. 에이전트도 `members` 그룹을 확인한다), `503`(데이터를 읽지 못함, 안내 문구 표시), `422`(계약 위반). 같은 `request_id`로 재시도하면 같은 응답을 돌려준다(spec 319).
- **`selectedStackId`는 `"{site_id}:{굴뚝번호}"`로 보낸다**(제안). 에이전트의 굴뚝 키가 이 형식이고, 화면 데이터에 둘 다 있다. 지도에서 고른 굴뚝이 스토어의 선택 굴뚝이므로 에이전트 창이 그대로 읽는다.
- CORS는 `https://smokestack-guard.store` 한 곳만 허용한다. 로컬 개발은 에이전트를 로컬로 띄우고 `APP_ORIGIN`을 맞춘다.

## 8. 확인하지 못한 것

- **네이버 지도(실제 SDK)**: 시험은 가짜 SDK로만 했다. 실제 인증(등록 도메인 통과), 실제 투영·타일 기준에서 핀이 어긋나지 않는지, `morph`가 의도한 부드러움인지, 더블클릭 확대와 핀 클릭이 섞일 때의 동작, `click`·`mousemove` 이벤트의 좌표 기준(`point` vs `pointerEvent`), 오른쪽 클릭·마우스 벗어남이 지도 위에서 실제로 오는지는 브라우저에서 확인해야 한다.

- A의 첫 화면이 실제 기기·해상도에서 어떻게 보이는지, `Pretendard`가 실제로 로드되는지(CSS가 이름만 지정하고 파일을 싣지 않음)
- 중간 프론트의 지도·차트·민감도 패널은 **파일 설명 줄 기준**으로만 파악했다. 각 단계를 시작할 때 해당 파일을 읽고 정확히 확인한다.
- 실제 Cognito 로그인 왕복 이후의 흐름(초대 코드 통과 → 대시보드)은 A의 구현을 읽기만 했다.

## 9. 하지 않는 것

- 이 spec에서는 파일을 옮기거나 `services/dashboard-web`을 수정하지 않는다.
- CI·Terraform·버킷 설정은 A가 한다.
- A의 로그인 화면(`Landing.tsx`, `LiveChart.tsx`)은 건드리지 않는다. 단계 판정 함수 변경은 나중에 A와 같이 한다.

## 운영 데이터 API (2026-11-21, D)

`services/dashboard-api`에 화면용 읽기 라우트를 추가했다(`app/dashboard.py`, 시험 `tests/test_dashboard.py`). RDS의 `ref`·`obs`(012)를 화면 모델(`src/data/model.ts`)로 바꿔 준다.

- `GET /api/sites`, `GET /api/day`(최신 시각 기준 30분 48칸, 적재가 :15·:45마다라 최신 시각이 같으면 캐시), `GET/PUT/DELETE /api/favorites`(`app.user_favorite`, Cognito sub 기준).
- 정상 칸은 숫자 문자열, 상태 칸은 `ref.status_code`의 원문 문구(미수신 등)로 준다. 값이 없는 칸을 0으로 채우지 않는다.
- DB 계정은 `tms_app`(IAM). **서버 역할의 `rds-db:connect`가 필요하다(A에게 요청).** 열리기 전에는 `DB_USER=tms_admin`으로 임시 확인한다.
- 화면 연결(완료): `useDay.ts`가 운영 빌드에서는 `/api/sites`·`/api/day`를(로그인 토큰, 갱신돼도 다시 읽지 않음), 개발에서는 `dev-data/`를 읽는다(`VITE_DATA_SOURCE=api|dev`로 바꿀 수 있다). 지역 경계·등고선은 사업장 정보가 없는 정적 파일이라 `public/map-data/`(개발·운영 공통, CDN 캐시)에서 읽는다.
- 30분 갱신(완료, 운영만): 적재가 :15·:45에 돌아 열어 둔 화면은 :17·:47에 `/api/day`를 조용히 다시 받는다. 최신 시각이 그대로면(아직 적재 전) 2분 뒤 다시(최대 5번), 실패해도 지금 데이터를 지우지 않는다. 숨은 탭이 다시 보이면 한 번 확인한다. 새 값으로 시점 목록이 한 칸씩 밀리면 고른 시점은 같은 시각을 가리키게 맞추고, 밀려 나가면 최신으로 간다.
- RDS 확인(2026-11-21, DBeaver): `tms_app` IAM 로그인·읽기·즐겨찾기 쓰기 권한 정상, 24시간 193,959행, 굴뚝 2,925개 전부 사업장에 연결, 시도 표기는 전체 이름(17개 모두 변환표에 있음), 굴뚝 번호 중복 없음.
- **즐겨찾기(2026-11-21, 같이 정한 것)**:
  - **단위는 사업장**(`app.user_favorite.target` = 사업장 코드). Cognito sub 기준으로 서버에 저장한다.
  - **저장 동작**: 별을 누르면 화면에 먼저 반영하고(낙관적) 서버에 PUT/DELETE, 실패하면 원래대로 되돌리고 4초간 안내한다. 처음에 `/api/favorites`를 읽고, 실패하면 화면 안에서만 쓰며 안내한다. 개발·시험은 서버를 부르지 않는다.
  - **쓰는 곳**: ① 경고 목록 안에서 위로 정렬 ② "★ 즐겨찾기" 칩(지도 상단과 목록 칩이 **같은 상태**) — 켜면 지도에는 즐겨찾기 사업장만 보이고(상태 칩은 함께 적용), 목록은 내 사업장을 **정상·공백까지 전국에서** 모아 보여 준다(지도 범위·지도 상태 칩과 무관, 목록 안 검색 가능) ③ 차트 머리의 별. 핀 위에 별 표시는 하지 않는다.
  - 알림 배너·알림 설정은 서버 알림 서비스가 정해진 뒤에 한다.
- 남은 일: A의 `rds-db:connect` 권한(`infra/stacks/tms-app/iam.tf` 변경 PR → A가 plan·apply).

## 방위·에이전트 창 가장자리 (2026-11-21, D)

- **방위(옛 웹에서 이식)**: 지도 오른쪽 아래에 N·E·W·S와 십자 별(북쪽 꼭지는 강조색)을 둔다. 지도는 늘 위가 북쪽이라 고정 표시이고 지도 조작을 가로막지 않는다(`src/map/Compass.tsx`). 안내 문구 줄 위(아래에서 44px)에 놓아 네이버 모드의 축척 막대와 겹치지 않는다. 글자는 13px, 색은 지도 전용 색(`--map-ink`)이라 라이트 테마의 어두운 지도 칸에서도 보인다.
- **에이전트 창 크기 조절 손잡이**: 두꺼운 초록 띠를 없앴다. 손잡이(가장자리 8px·모서리 18px)는 보이지 않고, 마우스를 올리거나 끌거나 키보드로 초점을 줄 때만 가장자리에 **2px 선이 은은한 빛(글로)과 함께** 켜진다. 모서리는 짧은 ㄱ자로 켜진다. 모션 감소 설정은 따로 줄 필요 없이 투명도 전환만 쓴다.

- **정정(2026-11-21)**: 에이전트 창 모서리 점등과 창 이동 중 전체 점등은 **유지**한다(D 확인). 다만 모서리가 켜질 때 네모난 영역이 보이던 것은 `box-shadow`가 14px 상자 전체로 번진 탓이라, 모서리는 창의 둥근 모서리 곡선(반지름 13px)과 같은 호만 그리고 `drop-shadow`로 호의 모양을 따라 빛나게 했다.
- **등고선은 일단 저장소에 올리지 않는다**(결정 2026-11-21, D: 나중에 추적 여부를 정한다). `public/map-data/contours/`는 `.gitignore`에 있고, 지역 경계(`geo.json`, 약 0.4MB)만 올린다. 운영 빌드에는 등고선이 없어 **관제 지도에서 등고선만 안 그려진다**(목록 읽기 실패는 조용히 넘어간다). 로컬에서는 `dev-data/contours/`(스크립트가 만든 것)를 `public/map-data/contours/`로 복사해 쓴다.

## 공지: 롤링 배너·스티커, 기본 상태 (2026-11-21, D)

옛 웹(`tms-frontend-midterm/public/ui/notice-banner*.js`)의 공지를 옮겼다. 관제 화면 본문 맨 윗줄(단계 카드 위)에 둔다.

- **판정은 최신 데이터 기준(실시간으로 본다)**: 지도 시각 슬라이더가 아니라 마지막 칸을 "지금"으로 본다. 굴뚝의 현재 비율은 마지막 칸에서 거슬러 올라가 값이 있는 첫 칸이고, **3시간(6칸)**을 넘게 오래된 값은 공지하지 않는다(옛 웹 규칙, `STALE_SLOTS`). 마지막 칸이 잠깐 공백이어도 직전 값이 있으면 공지가 깜박이며 사라지지 않게 하려는 것이다. 사업장마다 비율이 가장 높은 굴뚝 하나를 공지로 만든다.
- **롤링 배너(전국, 초과만)**: 지금 초과인 사업장을 비율 높은 순으로 세로 한 줄씩 3.5초마다 굴린다(끝에서 복제본으로 끊김 없이 처음으로). 마우스를 올리거나 키보드로 초점을 주면 멈추고, 누르면 그 사업장·굴뚝을 선택한다. 항목이 하나면 굴리지 않고, 움직임 줄이기 설정이면 굴리지 않고 ‹ ›로 넘긴다. 숨은 탭에서는 굴리지 않는다.
- **스티커(옛 웹의 공지 티커, 즐겨찾기만)**: 내가 즐겨찾기한 사업장 중 **경고 이상**(경고·위험·초과)인 곳을 칩으로 보여 준다. X로 닫으면 이번 탭 동안 기억하고(`sessionStorage`), 닫지 않은 새 공지(새 굴뚝·더 나빠진 단계)가 생기면 전체가 다시 나온다. 칩을 누르면 그 사업장을 선택한다. 이상 징후(예측)는 예측값이 없어 아직 없다.
- **지도 상태 칩의 기본**: 처음에는 **위험·초과만 선택**돼 있다(웹 기본). 나머지(정상·주의·경고·공백)는 칩으로 켠다. 경고 목록(검색어 없음)은 지도에 보이는 것을 따르므로 목록도 처음에는 위험·초과다.
- **알려 둘 점**: 위 3시간 규칙 때문에 롤링 배너의 초과 수가 단계 카드의 초과 사업장 수(마지막 칸만 센다)보다 많을 수 있다(마지막 칸이 공백인 사업장 포함). 같게 맞추려면 `STALE_SLOTS`를 1로 줄인다.

## 라이트 모드의 지도·그래프 (2026-11-21, D)

이전에는 라이트 모드에서도 지도 칸과 그래프 바탕이 어두웠다. 이제 둘 다 라이트를 지원한다.

- **대시보드 전용 바탕 색**: `--stage-bg`·`--stage-grid`(지도·그래프 바탕과 눈금)를 새로 두고 모드마다 값을 준다. A의 시작 화면(`landing.css`)이 쓰는 `--chart-bg`·`--chart-grid`는 **건드리지 않는다**(라이트에서도 어두운 미리보기 카드).
- **지도**: 라이트에서는 밝은 바탕에 흰 땅(`--map-land`), 옅은 경계선, 어두운 글자(`--map-ink`)와 선택 화살표(`--map-select`는 진한 호박색)를 쓴다. 핀의 배지 배경은 바탕색을 따른다. 공백 핀은 라이트에서 진한 회색(`--gap-from`).
- **등고선**: 라이트용 색상표(`RAMP_LIGHT`)를 따로 둔다. 같은 고도 단계(회녹 → 올리브 → 모래 → 흙 → 적갈 → 회갈)로 밝은 땅에서 보이게 더 진하고, 선 투명도는 1.35배다.
- **그래프**: 바탕·눈금이 밝아지고, 공백 구간 칠의 투명도는 라이트에서 절반으로 옅다(`--gap-fill-a/b`).
- 방위·툴팁·고르기 창도 같은 지도 색을 쓰므로 모드를 따라간다. 네이버 지도는 네이버가 그린다.

- **에이전트 창 가장자리 빛(라이트 모드, 2026-11-21)**: 라이트에서는 강조색이 진한 초록이라 그 색으로 번지면 빛이 아니라 그림자처럼 보였다. 선과 빛 전용 색 `--edge-light`(밝은 민트 `#3fbf93`, 두 모드 공통)를 두었다.
- **에이전트 창 가장자리 선의 연속성(2026-11-21)**: 변의 선이 모서리 호와 5px 벌어져 끊겨 보이던 것을 고쳤다. 변의 선을 양끝으로 5px씩 늘려(끌 수 있는 영역은 모서리에서 18px, 호는 13px에서 끝난다) 호와 맞닿게 하고, 선과 호가 같은 `drop-shadow` 빛을 쓰게 통일했다. 두 테마 모두 같다.

- **등고선은 기본이 꺼짐(2026-11-21, D)**: 등고선 자료를 저장소에 올리지 않아 운영 빌드에 없을 수 있으므로, 관제 지도의 "등고선" 버튼은 처음에 **끔**이다. 켤 때만 등고선 목록(`contours/index.json`)을 읽고, 꺼져 있으면 아무것도 요청하지 않는다(운영에서 없는 파일을 부르는 404도 없다). 한 번 읽으면 다시 읽지 않는다.

- **지도 시계 바늘·숫자(2026-11-21, D)**: 바늘의 화살촉을 없앴다. 시침(짧고 굵음)과 분침(길고 가늘음)은 길이로 구분되고, 끝이 둥근 막대 하나다(이전 결정 "시계 바늘은 화살표"를 대체). 12·3·6·9는 **로마 숫자 XII·III·VI·IX**(세리프 16px)로 바꾸고 밝은 민트 빛(`--edge-light`, 두 모드 공통)이 은은하게 번지게 했다. 숫자는 눈금 선과 겹치지 않게 안쪽에 놓고, 화면 낭독은 시각 설명(예: "지도 시각 오후 11시 30분")만 읽는다.
- **로마 숫자 자리(2026-11-21)**: XII·III·VI·IX는 12·3·6·9시 **눈금 자리**(원 중심에서 같은 방향, 반지름 78)에 서고 그 자리의 눈금 선은 없앴다(눈금은 8개). 3·9의 세로 중심은 원의 중심 높이(100)와 같다(글자 세로 중심은 `dy=0.35em`, 실제 화면에서 중심과 1px 이내로 확인). 글자는 15px.

## 그래프 설정 콘솔(톱니바퀴) (2026-11-21, D)

- **여는 곳**: 왼쪽 레일의 톱니바퀴(⚙, 테마 전환 위). 오른쪽에 뜨는 패널(`role=dialog`, 뒤를 가리지 않음, Esc·× 로 닫음)이고, 바꾸는 즉시 아래 추세 그래프에 반영된다. 사업장을 아직 안 골랐으면 "예시 사업장 열기"(지금 초과인 첫 사업장)로 그래프를 띄운다. "그래프로 이동" 버튼도 있다.
- **조절 항목**(기본값은 지금 모양 그대로): 선 굵기·부드러운 곡선(단조 보간, 없는 봉우리를 만들지 않음)·선 빛(라이팅) / 선 아래 영역 채움 켜기·진하기 / 값 없는 구간 점선 굵기·진하기·아래 칠 / 눈금선 켜기·진하기 / 주의·경고·위험·초과 기준선 켜기·점선·진하기 / 위쪽 20% 초과 영역 칠 / 안쪽 판 모서리 둥글기·바탕 진하기 / 선택 시점 세로선·점 크기·점 빛.
- **색**: 물질 색(NOx·SOx)과 영역·공백 점선·눈금선·초과 영역·주의/경고/위험/초과 기준선·안쪽 판 바탕·축 글자·세로선·점 테두리까지 모두 고를 수 있다(14개). 고르지 않으면 다크·라이트 테마에 맞는 기본색을 쓰고(영역·공백 점선은 물질 색을 따른다), 줄마다 "기본색" 버튼으로 되돌린다. 견본에는 지금 테마의 기본색이 보인다.
- **저장·공유**: 이 브라우저(`localStorage` `tms-chart-style`)에 저장한다. "현재 값 복사(JSON)"·"값 붙여 넣기"로 값을 나누고, "기본값으로 되돌리기"로 모두 초기화한다. 범위를 벗어나거나 모르는 값은 검사해서 맞춘다(`sanitizeChartStyle`). **마음에 드는 값을 복사해 알려 주면 기본값으로 반영한다.**
- **지도 위 등고선 버튼 위치**: `<등고선> 관제 일반 위성` 순서(지도 종류 선택 왼쪽). 네이버 모드에서는 등고선 버튼이 없다.

## 그래프 설정: 기본값·모드별·바깥 글자·박동 (2026-11-21, D)

- **기본값(D가 정한 값)**: 가는 선(1)·부드러운 곡선·선 빛 2px, 영역 0.4, 공백 점선 `#84b3a6`(굵기 1.5·진하기 0.5·칠 0.1), 눈금선 끔, 기준선 진하기 0.25, 안쪽 판 모서리 10·바탕 0.35, 점 크기 4·점 빛 2, 점 테두리 `#dbf6ff`, 세로선 `#000000`. 이전 기본 모양은 시험 도우미(`src/test/legacyChartStyle.ts`)에 남겼다.
- **다크·라이트 모드별 설정**: 모드마다 따로 저장(`tms-chart-style` = `{dark, light}`)하고, 모드를 바꾸면 그 모드의 설정이 적용된다. 패널 제목에 지금 모드가 보이고 "기본값으로 되돌리기"는 그 모드만 되돌린다. "다른 모드 설정 가져오기"로 반대 모드의 값을 복사한다. 두 모드의 기본값은 같되, **다크의 세로선만 테마 글자색**(검은 선이 어두운 바탕에서 안 보여서)이다. 예전 저장값(모드 구분 없음)은 두 모드에 모두 넣어 읽는다.
- **바깥 글자·숫자**(크기 16~28px — 그림이 줄어드는 화면을 감안해 16 아래로는 못 내린다, 빛 0~14px, 색): "기준 초과 영역(압축)" 글자 / 오른쪽 단계 글자(초과·위험·경고·주의, 색은 각 기준선 색을 따름) / 축 숫자(% 눈금·시각, 색은 축 글자 색). 키워서 그림 가장자리를 넘어도 잘리지 않는다(`overflow: visible`).
- **점의 단계 글자만 보이기**(옵션, 기본 끔): 그래프에서 점을 찍으면(클릭, 안 찍으면 최신 점) 그 점의 %(두 물질이면 높은 쪽)가 속한 단계 글자 하나만 남는다. 70% 미만(정상)이면 모두 숨는다. 기준선은 그대로 둔다.
- **박동(두근두근)**: 로그인 화면의 `.heartbeat`(두 번 부풀고 쉰다: 1 → 배율 → 1 → 중간 배율 → 1, 뒤에서 빛이 번짐)를 그래프 글자에 옮겼다. **선택한 점의 %가 속한 단계 글자 하나가 박동**한다(기본 켬, 정상이면 박동할 글자 없음). 배율(1.02~1.6, 기본 1.09)·한 번 뛰는 시간(0.4~3초, 기본 1.25)·번지는 빛(0~20px, 기본 8)을 조절하고, "높은 단계일수록 빠르게"(기본 켬)는 초과 0.64배·위험 0.8배다(로그인 화면의 0.8초/1.25초와 같은 비율). 움직임 줄이기 설정에서는 멈춘다.

- **모드별 기본값 확정(2026-11-21, D)**: 다크와 라이트 각각 D가 그 모드에서 고른 값을 기본으로 한다(`DEFAULT_CHART_STYLE_DARK`·`DEFAULT_CHART_STYLE`). 두 모드의 틀(가는 곡선·눈금 끔·단계 글자 23px 하나만·축 숫자 19px·박동 1.38배/1.55초)은 같고 다음만 다르다(8개).

  | 항목 | 다크 | 라이트 |
  |---|---|---|
  | 초과 영역 글자 색 / 빛 | `#ffffff` / 2px | `#ababab` / 0 |
  | 초과 영역 칠 색 | 테마색 | `#ff0a0a` |
  | 세로선 색 | `#ffffff` | `#000000` |
  | 축 글자 색 / 빛 | `#ffffff` / 2px | `#599765` / 1px |
  | 단계 글자 빛 | 2px | 1px |
  | 박동 빛 | 6px | 2px |

  점 테두리(`#dbf6ff`)·공백 점선(`#84b3a6`)은 같다(세로선은 다크 흰색, 라이트 검정 — 처음 정리할 때 라이트를 흰색으로 잘못 적었다가 정정). 이미 이 브라우저에 설정을 저장해 둔 사람은 저장값이 우선이므로, 새 기본값을 보려면 패널의 "기본값으로 되돌리기"를 한 번 누른다.

## 지도 축소·이동 한계 (2026-11-21, D)

- **관제 지도**: 전국이 화면에 여백 28px로 꽉 차는 배율(= "전국 보기")보다 더 줄일 수 없다(`minScaleFor`). 이동은 지도 범위 가장자리가 화면 안쪽 25%보다 더 들어오지 못하게 붙든다(`clampView`): 지도가 화면보다 작으면 가운데에 고정하고, 화면보다 커질수록 이동 여유가 25%까지 서서히 늘어난다. 휠 축소·끌기·"크게 날아가기"(묶음 확대·사업장 선택·전국 보기)·창 크기 변경 모두에 적용된다. 그래서 지도가 점처럼 작아지거나 화면 밖으로 밀려나지 않는다.
- **네이버 지도**: 확대 한도를 6에서 **7**로 올렸다(7 미만은 한국이 아주 작고 주변 바다·외국만 보인다). 이동은 기존대로 한국 범위(`maxBounds`) 안이다.
