# 기능 명세: 승인된 단일·복합 도구 실행 계획

**기능 번호**: 305 · D 분석·화면·RAG  
**작성일**: 2026-11-14  
**상태**: 로컬 실행 전 계획 검증 범위  
**입력**: 사용자의 ‘단일 도구나 복합 사용을 명령 분석 시 조합하도록 정하고 의견을 포함해 작업’ 요청. 303의 일반 복합 실행 대기는 이번에 승인한 제한된 계획 검증 범위에서만 확장한다. 브랜치 생성·전환은 하지 않는다.

## 사용자 시나리오와 검증

### US1 — 허용 능력과 단일 요청 확인 (P1)

관제 사용자는 어떤 결과를 제공할 수 있는지 확인하고 한 요청을 허용된 기능으로 변환한다.

독립 검증: 기존 사업장 이동·수치 조회는 조건을 보존하고, 유량 없는 kg 배출 총량은 현재 자료로 계산 불가를 안내한다.

1. 대상과 시각을 명시한 NOx 조회는 해당 조건을 그대로 보존한다.
2. 유량이 필요한 배출 총량 요청은 유량을 추정하거나 확인 카드를 반복하지 않고 자료 부족으로 안내한다.
3. 대출·기록 변조·비공개 접근은 기존 범위 밖/차단 기준을 유지한다.

### US2 — 승인된 복합 요청을 같은 조건으로 구성 (P1)

사용자는 NOx·SOx 각각의 평균, 한 물질의 평균·최댓값, 경고 근거와 대응 문서, 서로 다른 두 물질의 표시 변경을 함께 요청한다.

독립 검증: 두 물질 평균은 두 개의 집계 요청으로 구성하되 같은 대상·기간을 쓰며, 요청하지 않은 물질·동작을 더하지 않는다.

1. 두 물질 평균에서 시각이 빠지면 공통 시간 카드 한 번으로 보완하고 두 단계에 같은 값을 반영한다.
2. 경고 근거와 대응 문서 요청은 관측 근거 확인 후 관련 문서 검색의 순서와 의존성을 공개한다. 법령 기준일을 임의 확정하지 않는다.
3. 같은 물질을 동시에 켜고 끄는 상충 요청은 확인 전 준비 완료가 되지 않는다.
4. 등록되지 않은 도구 순서·임의 실행문·숨은 추가 단계는 거절한다.

### US3 — 결과 상태와 일부 실패를 구분 (P2)

사용자는 관측 설명은 확보했지만 문서를 못 찾은 경우, 확보한 내용과 실패한 내용을 구분해 안내받는다.

독립 검증: 성공·검색 결과 없음·읽기 실패·의존 단계 미실행 표본을 서로 다르게 표시하고, 미실행 지도 이동을 성공이라 부르지 않는다. 이번에는 실제 도구 호출 없이 결과 상태 대조기로 검증한다.

### 경계 사례

부분 이름·동명·빠진 시간은 확인한다. 문맥 변경·만료된 카드·조작된 단계·서로 다른 공유 조건·해석안의 명시 조건 변경은 준비 완료를 막는다. 단순 법령 검색과 시설별 법적 적용 판단을 구분한다. 예측·비교·추세·지역 집계는 연결 대기 또는 별도 정의 필요로 공개한다.

## 요구사항

- **FR-001**: 허용 능력·현재 처리 상태·필수 조건·필요 자료·제외 범위를 한 목록에서 확인할 수 있어야 한다.
- **FR-002**: 요청 계획은 승인된 단일 또는 복합 순서만 사용하고, 복합 계획은 이번에는 2단계로 제한한다.
- **FR-003**: 단계별 대상·물질·기간·동작과 순서·의존성을 공개하고 원문에 없는 조건을 임의로 채우지 않는다.
- **FR-004**: 모든 단계는 같은 공통 조건 검증을 통과해야 하며 공유할 조건은 같은 값이어야 한다. 문서 기준일과 관측시각은 별개다.
- **FR-005**: 조건 누락은 해당 조건 카드, 자료 미보유는 자료 부족, 기능 미지원은 연결 대기, 해석 불확실은 해석 후보로 구분한다.
- **FR-006**: 해석안은 허용 순서와 조건을 재검증하며 사용자의 최종 해석 확인 전에는 준비 완료가 되지 않는다. 명시 조건과 다른 해석안은 거절한다.
- **FR-007**: 결과 상태 대조는 확인된 일부 성공과 문서 없음·실패·의존성 차단을 구분한다. 근거 없는 설명·미실행 성공 주장은 허용하지 않는다.
- **FR-008**: 기존 사용자 검토 화면에서 단일·복합 계획과 조건 보완 내역을 볼 수 있고 저장할 수 있어야 한다. 기대값을 명령으로 주입하지 않는다.
- **FR-009**: 로컬 검증 중 실제 모델·클라우드·DB·지도·외부 연락 호출은 0회다. 팀 데이터 계약을 확정하지 않는다.

### 핵심 정보

능력 목록, 승인 순서, 원문 요청, 단계별 조건, 공유 조건, 확인 카드, 결과 상태, 근거 출처, 해석 확인 기록.

## 성공 기준

- **SC-001**: 고정한 단일·복합·반례 표본에서 도구·순서·대상·물질·시각·연산이 모두 기대와 일치한다.
- **SC-002**: 상충·누락·조작·미지원·부족 자료 표본의 확인 전 준비 완료 및 실제 실행은 0건이다.
- **SC-003**: 공유 조건은 한 번의 선택으로 모든 관련 단계에 반영되고 이전 카드가 새 질문을 바꾸는 사례는 0건이다.
- **SC-004**: 결과 없음·실패·일부 성공·의존성 차단 표본을 모두 구분한다.
- **SC-005**: 직접 입력·계획 표시·카드 보완·문맥 변경·기존 단일 요청의 브라우저 회귀를 통과한다. 개발 세트를 독립 사용자 정확도로 표현하지 않는다.

## 전제와 의존성

후속 [306 사업장 지도 이동](../306-agent-site-navigation/spec.md)은 관제 질문창의 단일 사업장 선택만 실제 실행하도록 별도 연결한다. 이 305의 일반 계획·복합 실행기는 미연결 상태를 유지한다.

기존 303의 도구·권한/시각 검증과 로컬 실험실을 재사용한다. 이번 승인은 제한된 계획 작성·결과 상태 검증이며 운영 실행 승인이나 C/E의 계약 확정이 아니다. 운영 인증·실제 실행기·모델/문서 결과 표준은 후속 연동 대상이다. 추가 분석 기능은 사용자 정의와 팀 제공 항목을 받아 별도 기능으로 확장한다.
