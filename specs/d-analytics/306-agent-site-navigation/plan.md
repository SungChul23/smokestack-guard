# 구현 계획: 사업장 지도 이동 실행 연결

2026-11-14 · [명세](spec.md) · 브랜치 작업 없음.

## 요약

기존 `StackDashboard.selectSite`는 검색/상태 필터에 의해 다른 사업장으로 재선택될 수 있으므로, 기존 동작은 그대로 두고 `selectSiteForAgent`라는 좁은 함수를 추가한다. 이 함수는 필요한 필터만 완화하고 기존 pick/render/focusSite를 사용한다. 공통 검증으로 만든 control_view/select_business 명령만 새 실행기에 전달한다.

## 기술 환경

기존 JavaScript·정적 HTML·Node test·브라우저 CDP를 사용한다. 새 설치·서버·외부 호출·비용 없음. 작은 core 번들은 기존 분류기 모듈만 묶으며 LLM이나 8767 서버를 요구하지 않는다. 에이전트 창의 등록 명단/명령 검증을 사용한다고 표시하고 형태소 서버를 호출했다고 주장하지 않는다.

## 원칙 점검

수집·원본·Silver·판정·예측 불변, 비밀값/클라우드 미사용, D 폴더/번호 준수, 원문/명령/결과 추적, 오류를 성공으로 숨기지 않음. 사전/설계 후 모두 통과. 운영 인증은 범위 밖이며 공개 UI 탐색만 실행한다.

## 구조

- `D/site-navigation/build-core.cjs`: 기존 공통 분류기를 브라우저 번들로 재사용한다.
- `ui-review-20261109/site-navigation-executor.js`: 순수 명령 검증과 좁은 컨트롤러 어댑터. 표시 확인 최대 3초, 요청 취소/새 선택 시 재이동하지 않는다.
- `console-app.js`: `selectSiteForAgent`는 명단·좌표·필터를 검사하고 기존 렌더러로 갱신한다.
- `agent-site-navigation.js/.css`: 질문창 상위 capture에서 사업장 요청만 처리한다. 후보·취소·결과를 표시하고 나머지는 기존 검색으로 통과시킨다.
- `agent-shell.js`, `agent-exceedance.js`, `hatch-thin.html`: 질문 안내/취소·로딩 충돌만 좁게 연결한다.
- 단위/실제 관제 브라우저 테스트로 성공·이미 보임·필터 제외·부분 이름·미등록·오류·취소·기존 기능을 검증한다.

## 제약

이동의 원자적 되돌리기는 제공하지 않는다. 선택 적용 뒤 사용자가 취소해도 이미 바뀐 화면을 자동 복구하지 않는다. 실제 선택은 됐지만 표시 확인이 실패하면 partial로 안내한다. 자동 네이버 SDK/API 호출을 시험에 추가하지 않고 공통 인터페이스는 표본으로 검사한다.
