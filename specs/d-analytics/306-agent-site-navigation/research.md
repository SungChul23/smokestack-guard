# 설계 결정

- 기존 함수 재사용과 별도 어댑터를 선택했다. DOM 버튼을 찾아 클릭하거나 임의 함수를 실행하는 대안은 상태/성공 확인이 어렵다.
- 8767과 cross-origin 메시지를 주고받는 대신 관제 페이지 안에서 명단과 공통 검증을 사용한다. 별도 로컬 서버 없이 동작하고 질문을 외부에 보내지 않는다.
- 필터는 대상 표시를 막는 경우에만 완화한다. 전체 상태/검색을 무조건 초기화하는 대안은 사용자가 정한 화면 조건을 불필요하게 잃게 한다.
- 원문이 확정되지 않은 부분 이름은 유일 후보라도 확인한다. 잘못된 이동보다 사용자 확인이 낫다.
- 지도 함수 호출만으로 성공 처리하지 않는다. selectedSite와 실제 지도 그룹의 대상 포함을 확인한다.
- 법령 검색·초과 조회 취소를 연동하고 새 요청이 오래된 성공 안내를 받지 않게 한다. 신규 미해결 기술/계정 의존성은 없다.
