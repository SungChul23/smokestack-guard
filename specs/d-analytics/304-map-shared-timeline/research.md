# 설계 근거

- 현황: 기존 prepare는 각 굴뚝 최신 관측과 7종 최대 비율을 사용했다. 지도 공통 시각이 아니다.
- 결정: 정확 시각의 NOx/SOx 판정. 타 시각 숫자로 대체하는 대안은 미관측을 숨기므로 제외했다.
- 결정: 원문 이력으로 48개 프레임 정적 생성. 일별 순위 파일은 원문 상태 소실로 제외했다. 브라우저에서 909개 사업장 파일을 읽는 대안은 요청량 때문에 제외했다.
- 결정: 지도 시간과 차트 시간을 분리한다. 과거 재생이 차트 범위/사업장 이력 로딩을 반복시키지 않게 한다.
- 결정: 예측은 대기 칸만 둔다. 모델 계약 미수령 상태에서 가짜 예측은 만들지 않는다.
- UI: ui-ux-pro-max의 reduced-motion/auto-rotating-controls 검색 결과를 참고해 자동 재생을 하지 않고 정지/앞뒤/키보드를 제공한다.
- 저장소 검토: plan 스킬 연구 단계의 읽기 전용 검토를 요청했다. 외부 조사/자격증명 사용 없음.
- 검토 반영: 차트의 기존 latest/observations를 수정하지 않고 mapLatest/mapState로 분리했다. 재생 갱신에서 일반 render/notify를 호출하지 않아 자동 선택·카메라 이동·차트 이력 재요청을 피한다. 상단 집계·목록은 같은 투영 ratio를 읽는다.
