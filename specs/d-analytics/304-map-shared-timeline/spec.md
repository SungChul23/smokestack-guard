# 기능 명세: 지도 공통 시각·하루 재생

**기능**: D 304 · **작성일**: 2026-11-13 · **상태**: 사용자 요청으로 구현 진행  
**Git**: 기존 main 유지. 기능 이름은 브랜치 생성이 아니다.

## 사용자 시나리오와 검사

### US1 — 같은 시각의 두 물질 관제 (P1)

사용자는 지도에 함께 표시되는 굴뚝들이 같은 시점의 상태인지 알아야 한다.

독립 검사: NOx/SOx 정상·초과·문자상태·NULL·정확한 시각의 기록 없음·다른 물질만 초과인 표본을 함께 표시한다.

1. 최초 진입 시 최신 **보관 측정시각**을 지도 전체 공통 기준으로 고정한다. 실제 현재시각/실시간이라고 표현하지 않는다.
2. NOx/SOx만 지도·목록·상단 집계 판정에 반영한다. 화면 상태 경계는 기존 팀 변경 가능 설정을 사용하며 수치상 >100% 조회 정의와 구분한다.
3. 시각이 다르면 이전 정상/숫자로 대체하지 않는다. 해당 시각 원문이 문자/NULL이면 숫자로 바꾸지 않고 미판정으로 표시한다. 한 물질만 숫자라면 해당 숫자로 상태를 정하되 다른 물질 결측을 감추지 않는다.

### US2 — 최신까지 24시간 48칸 탐색·재생 (P1)

독립 검사: 48개 끝시각, 앞뒤 이동, 수동 탐색, 최신 복귀, 재생 종료를 확인한다.

1. 48칸은 `(최신-24시간, 최신]`의 측정 종료시각이다. 최신-23시간30분부터 최신까지 30분 간격이며 달력 하루와 혼동하지 않도록 명시한다.
2. 선택 시각에 지도·상태 집계·사업장/굴뚝 목록이 함께 갱신된다. 차트의 독립 조회 기간과 보관 기준시각은 바꾸지 않는다.
3. 재생은 사용자 실행으로만 시작하고 마지막 칸에서 멈춘다. 중지·탐색·최신 복귀·탭 숨김 시 멈춘다. 카메라를 자동 이동하지 않는다.
4. 자료 읽기 실패 시 최신 지도를 유지하고 재시도 안내한다. 늦은 응답이 최신 복귀/다른 선택을 덮어쓰지 않는다.

### US3 — 미래 초과 예상 칸의 빈 상태 (P2)

독립 검사: 예측 미연결 상태에서 가짜 목록·0건 단정을 표시하지 않는다.

예측 결과가 아직 없으므로 ‘예측 데이터 연결 대기’만 표시한다. 과거 초과나 보간값으로 예측을 만들지 않는다. 모델 출력 계약·예측 시간/유효기간·초과 정의는 E 수령 후 별도 작업한다.

### 경계 사례

- 최신이 자정/하루 일부, 날짜 경계, 완전 결측 칸, 모든 굴뚝 결측, 수치 0, 문자열 상태, NULL, 유효하지 않은 기준값.
- 로딩 중 최신 복귀/새 시각 선택, 재생 중 탭 숨김, 두 지도 배경 전환, 상태 필터로 현재 굴뚝 제외.

## 요구사항

- FR-001: 지도 판정은 공통 정확 시각과 NOx/SOx만 사용한다. 최신 숫자를 찾기 위해 과거로 돌아가지 않는다.
- FR-002: 원문 관측 유무와 문자열·NULL을 보존한다. TSP/HCl 잠금 UI를 만들지 않는다.
- FR-003: 하단에 시간 라벨·0~47 탐색·이전/다음·재생/정지·최신 복귀를 제공한다. 키보드 조작을 지원한다.
- FR-004: 기본은 최신 고정이고 과거 48칸은 조작 때 필요한 로컬 자료를 한 번 읽어 재사용한다. 외부 API·운영 인증을 추가하지 않는다.
- FR-005: 최신과 과거에 같은 판정 함수를 쓴다. 사업장 대표값은 해당 시각 소속 굴뚝 지원 물질의 최대 비율이며 판정 가능한 값이 없으면 미판정이다.
- FR-006: 차트 원문 이력·좌표·기존 지도 드래그/전환·질문/법령 검색을 유지한다. 지도 시간과 차트 조회 시간을 각각 명시한다.
- FR-007: 미래 예측 칸은 실제 예측 연동 전 대기 상태이며 0건으로 표현하지 않는다.

### 주요 개체

- 지도 시간: 최신 보관시각, 선택시각, 최신/과거 모드, 재생 여부.
- 시점 자료: 정확한 48개 끝시각과 원문 NOx/SOx 값·기준값·내부 굴뚝 ID.
- 지도 판정: 관측 유무, 숫자 여부, 물질별 비율, 대표 상태.

## 성공 기준

- SC-001: 경계 표본에서 타 물질 초과/과거 수치/NULL이 잘못 정상·초과로 분류되는 경우 0건.
- SC-002: 모든 48칸에서 모든 지도 대상이 같은 선택시각을 공유하고 최신 복귀 시 최초 최신 상태를 복원한다.
- SC-003: 첫 화면 재생 파일 요청 0회, 첫 탐색 후 같은 파일 추가 요청 0회.
- SC-004: 원본 수집/자료·좌표 변경 및 외부 모델 호출 0회. 가짜 예측 목록 0개.
- SC-005: 지도 전환·키보드·모바일·정지/늦은 응답 대표 검사가 통과한다.

## 가정과 범위

사용자 추가 승인 — 마커 효과 구현: 지원 물질의 화면상 초과(≥100%)가 새로 보이는 경우 붉은 타원 파동을 1회 표시한다. 기존 마커는 동일 대상 키로 유지하고 상태색을 350ms 전환한다. 새 일반 대상은 220ms 등장, 제외 대상은 180ms 퇴장 후 제거한다. 퇴장 대상은 즉시 상호작용/접근성 대상에서 제외한다. 카메라 이동 중에는 진입/퇴장 효과를 생략하고 좌표를 보간하지 않는다. 효과는 표시 시점 사이의 차이이며 실제 신규 초과 사건 발생 판정이 아니다. 관제/네이버 양쪽에 적용하고 모션 감소 설정에서는 장식을 제거한다. 이전 ‘추천만’ 범위를 이 승인으로 대체한다.

추가 사용자 조정: 최초 시계는 좌상단의 작은 버튼으로 접고 클릭 시 펼친다. 접기/ESC는 재생을 멈추고 선택 시각을 유지한다. 플립은 숫자 의미를 즉시 바꾸되 위/아래 판이 실제로 접혀 넘어가는 효과로 표시한다. 기본 재생 간격은 1.6초(느림 2.4초/빠름 0.8초), 플립 최대 760ms로 읽을 시간을 남긴다. 빠른 탐색은 이전 효과를 취소하고 모션 감소 설정에서는 애니메이션을 제거한다. 굴뚝 표시 전환 방식은 추천만 요청했으므로 이번 UI 수정에서 마커 렌더러는 변경하지 않는다.

2026-11-13 후속 화면 요청: 지도 아래의 가로 막대·긴 설명·분리된 예측 안내 칸을 제거한다. 지도 내부에 24시간 원형 시계(48개 반시간 눈금)와 년/월/일/시/분 플립 표시를 둔다. 바늘 드래그는 놓을 때 적용하며 단일 클릭·앞뒤 버튼·키보드 대안을 유지한다. 미래 초과 예상은 우측 경고 라인업의 관측/예상 토글로 옮기고 최신 보관 기준시각을 고정해 표시한다. 과거 지도 재생이 예상 목록 기준을 바꾸지 않아야 하며, 미연결일 때 예상 토글은 대기 상태만 보인다. 자동 재생·가짜 예측·새 모델 계약을 추가하지 않는다.

‘하루’는 최신까지 24시간으로 해석한다. 임시 재생 간격 1초/칸이며 속도 선택을 지원한다. 기존 화면 상태 분류를 재사용하고 실버/모델 계약은 만들지 않는다.
