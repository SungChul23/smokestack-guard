Python 3.12와 Node는 현재 설치 환경을 사용한다. 추가 설치·자격 증명이 필요 없다. 이 Windows 환경의 `python3` 별칭은 실행되지 않아 같은 Python 3 인터프리터인 `python`으로 Spec Kit Python 스크립트를 실행했다. 설치 스크립트는 변경하지 않았다.

1. `python D/law-evidence-search/build_corpus.py`로 공식 원문 해시·메타와 조문을 검사하고 공개 자료를 만든다.
2. `node D/law-evidence-search/test-law-search.cjs`로 대표 질문·원문·시점·실패 경계를 검사한다.
3. 기존 관제 서버 `http://127.0.0.1:8765/`를 열고 우측 에이전트 창에서 근거 검색을 실행한다.
4. 대표 질문: 배출허용기준 초과 시 개선명령 근거 / 측정기기 고장 관리 규정 / 개선계획서 제출 / 개선계획서 내용 / 개선명령 이행 보고 / 개선명령을 받지 않은 사업자의 계획.

6. 개발자 도구에서 corpus 파일 요청을 차단해 자료 읽기 실패와 재시도를 확인한다. 빈 검색 결과와 구분해야 한다.
7. 다크·라이트, 모바일 너비, 키보드 초점, 지도·측정 그래프·질문창 닫기를 확인한다.

현재는 공식 근거 검색 단계다. 생성 LLM·벡터 검색·운영 경고·시설별 법적 판단은 구현 결과로 주장하지 않는다. NAVER 화면은 기존 승인된 Client ID 입력 이후 동일 검색 모듈을 불러오며, 새 자격 증명을 요구하지 않는다.
