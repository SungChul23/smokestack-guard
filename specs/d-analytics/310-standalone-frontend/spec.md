# 기능 명세: 관제 프론트 독립 분리

작성일: 2026-11-16 · 담당 D · 사용자 요청: 지도·프론트만 복사 분리해 jaeyan42/tms-frontend 공개 저장소로 준비.

## 사용자 시나리오
- US1(P1): 기존 화면의 실제 실행 의존성만 별도 디렉터리에 복사한다. 원본 작업은 유지한다. 지도·차트·테마·사업장 선택·네이버 지도 전환을 보존한다.
- US2(P1): 사용자가 선택한 보관본 최신30분만 포함하고, 다른 측정시각·과거 이력·하루 재생·원본 수집 자료는 포함하지 않는다. 자료 범위와 실시간 미연결을 표시한다.
- US3(P2): 별도 저장소에서 정적 프론트로 실행·배포할 수 있고 불필요한 사진·검토/분석/학습 도구·캐시·비밀값은 배포본에 없다.

## 요구와 경계
- 실제 HTML/CSS/JavaScript와 동적 지도/등고선 의존성을 추적한다. 제거한 기능의 파일을 실행 중 다시 요청하지 않는다.
- 사업장 메타·한국 지도 좌표/경계와 최신30분 NOx/SOx 자료만 포함한다. 현재 시각의 실측이라고 주장하지 않는다.
- 이력/재생은 데이터가 없음을 표시하고 기존값을 채워 넣지 않는다. 백엔드·LLM·임베딩 모델·로컬 실험 서버는 복사하지 않는다.
- 원본 파일·Git 이력을 삭제·이동·병합하지 않는다. 공개 저장소 생성/업로드의 인증·권한은 별도 확인한다.

## 검증 기준
독립 폴더만 제공한 HTTP 서버에서 실제 브라우저로 실행한다. 로컬 자산404·JS 예외가 없어야 하며 다른 프로젝트 폴더의 파일을 참조하지 않는다. 모든 관측은 같은 최신30분 구간에 속해야 한다. 파일 목록·크기·제외 항목을 기록한다.
