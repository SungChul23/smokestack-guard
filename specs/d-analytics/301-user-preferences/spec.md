# 기능 명세: 로그인 사용자별 관심 사업장·알림 설정 초안

작성: 2026-11-11. 상태: 로컬 프론트 MVP. 브랜치 생성 없음.

## 사용자 시나리오 및 검증

### US1 — 로그인 상태 구분 (P1)

비로그인 사용자는 관제 화면을 조회하고, 데모 계정을 선택해 로그인한 사용자만 개인 설정을 변경한다. 사용자 전환·로그아웃·새로고침을 확인한다. 데모 로그인은 실제 계정 인증을 의미하지 않는다.

### US2 — 사용자별 사업장 즐겨찾기 (P1)

로그인 사용자는 선택한 사업장을 즐겨찾기에 추가·삭제하고 목록에서 이동한다. 전체 사업장 검색으로도 추가할 수 있다. A의 목록은 B에게 보이지 않으며 같은 브라우저에서 재로그인하면 유지된다.

### US3 — 사용자별 이상 알림 설정 (P2)

로그인 사용자는 즐겨찾기 사업장에 대해 이메일/Slack, 수신 대상, 실제 기준 초과/예측 경고 유형, 알림 사용 여부를 저장한다. 미설정·잘못된 대상은 안내하고 저장하지 않는다. 알림 시연은 조건을 만족한 경우에만 미발송 미리보기를 보여준다.

## 요구사항

- FR-001: 로그인하지 않은 사용자의 모든 개인 설정 변경 경로를 차단한다.
- FR-002: 사용자별 즐겨찾기·알림 설정을 분리하고 로그아웃 시 화면의 개인 내용을 제거한다.
- FR-003: 사업장 식별은 공개 사업장 코드로 하며 존재하는 사업장만 저장한다.
- FR-004: 관제 지도·차트·질문·기존 좌표 보정과 909곳 검토 기록은 유지한다.
- FR-005: 수신 채널·대상·유형·즐겨찾기 유무를 검증한다. 비밀키·웹훅 URL은 받지 않는다.
- FR-006: 실제 외부 발송은 이번 범위에 포함하지 않으며 시연 결과를 발송 성공처럼 표시하지 않는다.
- FR-007: 기존 측정자료·MOCK·과거 경고를 실제 신규 경보로 자동 전송하지 않는다.
- FR-008: 저장 오류·로그아웃·계정 전환·다른 탭 변경을 처리하고 키보드·모바일 사용을 지원한다.

## 핵심 개체

데모 세션, 사용자 설정, 사업장 코드 목록, 알림 설정, 명시적으로 선택한 시연 사건. 이메일 등 입력값은 소스·로그·백업 파일에 쓰지 않는다.

## 성공 기준

- 두 데모 계정의 즐겨찾기·설정이 섞이지 않는다.
- 비로그인 변경, 입력 오류, 조건 없는 알림 시연이 차단된다.
- 새로고침·재로그인 후 개인 설정이 복원된다.
- 알림 시연 중 외부 네트워크 발송 요청은 0건이다.
- 기존 화면은 로그인 없이도 조회할 수 있다.

## 가정 및 경계

사용자의 ‘프론트에 간단하게’ 요청에 따라 계정 두 개를 선택하는 데모 로그인으로 시작한다. 서버 인증·권한·메일/Slack 발송·자동 경보 감지는 추후 A/E와 계약을 정하고 외부 설정 승인을 받은 뒤 연결한다. 예측 경고를 법적 기준 초과로 바꾸어 설명하지 않는다.
