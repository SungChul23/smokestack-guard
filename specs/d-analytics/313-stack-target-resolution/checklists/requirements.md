## 기능 준비 상태

- [x] 모든 요구사항이 성공 기준 또는 시나리오로 확인된다.
- [x] 주요 흐름(자동 선택, 카드, 없음→지역→지도, 번호 모름, 별칭, degrade)을 시나리오가 덮는다.

## 이 명세가 아직 모르는 것

- 실제 사용자 표현 분포(별명, 번호 모름 비율). 세트는 LLM이 만든 것이고 번호가 있는 질문만 썼다.
- 화면 선택이 들어왔을 때의 후보 우선순위 효과.
- 임계값 2.5의 실제 질문에서의 적정성.
