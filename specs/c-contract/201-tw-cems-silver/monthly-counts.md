# 대만 CEMS 월별 단계별 행 수와 양성 수

tasks T011(FR-016, SC-006)과 T019의 기록이다. 2026-11-10 기준, 36개월(2023-11 ~ 2026-10) 전체 실행 결과이며 ML-ready의 월은 `measured_at`(대만 현지 시각) 기준이다. 입력은 **재수집한 원본(`s3://smokestack-tms-raw-952900391026/bronze2/tw_cems/`)** 이고, ML-ready는 `quality_policy_version = v2` 규칙이다. 로컬 pandas로 만들었다.

- 모든 달에서 `ok` + `not_monitored` + `other_code` + `partial` + `invalid` = 슬롯 수이다(SC-001).
- 재수집 원본은 36개월 모두 `_id`가 1부터 끝까지 연속이고 중복이 0이며, 줄 수가 서버가 알려 준 총 행 수와 같다. 합계 159,725,257행은 재수집 전과 같지만, 이전 원본에는 월마다 1.3~2.7%의 행이 중복되고 같은 수만큼 빠져 있었다(offset 페이지네이션에 정렬이 없던 탓).
- 재수집 전(80,359,440슬롯, `ok` 24,743,836, `partial` 약 455만)과 비교하면 슬롯이 22,548개, `ok`가 1,111,015개 늘고 `partial`이 크게 줄었다. 합계 `partial`은 1,202,295이다.
- ML-ready 학습 가능 행은 재수집 전(9,857,883, v2)보다 43.6% 늘었다(14,158,991). 빠진 행 하나가 앞뒤 연속 6슬롯 조건을 깨던 효과가 사라졌기 때문이다. 양성은 133,715에서 181,231이 되었고 양성 비율은 1.36%에서 1.28%이다.
- 양성이 0인 달은 없고, 월 2,608(2024-03) ~ 7,585(2026-05)행이다.
- 2023-11(11-27 16:30 이후)과 2023-12(첫 6시간 반)는 재수집 후에도 원본이 비어 있다. 서버 원본 자체의 공백으로 보인다.
- **Glue와 일치한다.** 재수집 원본(`bronze2/tw_cems/`)으로 Glue를 다시 실행한 결과(`silver2/`, 성철 님, PR #37)와 비교했다.
  - Silver: 36개월 모두 입력 행, 슬롯, `status` 5종이 일치한다(합계 80,381,988슬롯).
  - ML-ready: 행 18,436,379, 분류 학습 가능 14,158,991, 양성 181,231, 회귀 학습 가능 14,664,879가 일치한다(NOx·SO₂ 각각도 같음). Glue의 compare는 행 18,436,379개 양쪽 동일, 한쪽에만 있는 행 0, 값 불일치 0이며 이동 평균·표준편차 등은 부동소수점 오차(최대 `ratio_rolling_std_3h` 6e-6, 허용 1e-5)만 있다.
  - 재수집 전 원본으로 만든 Glue 결과(PR #31, 80,359,440슬롯)와 pandas도 36개월 모두 일치했었다.

## 표본 검증 (T017, T018)

학습 가능 행에서 양성 500, 음성 500을 뽑아(NOx 667, SO₂ 333, 263개 굴뚝) Silver 원값에서 다시 계산해 ML-ready와 비교했다.

- Feature(Lag 5개, 변화량, 이동 평균·표준편차·최대·범위, 기울기, 상승 횟수, 가속도, 시간 주기, 여유율)를 **과거와 현재 슬롯만** 써서 재계산했다. 1,000행 모두 모든 컬럼에서 일치했다.
- 정답 `label_ratio_60m`과 `label_entry_60m`을 `t+30분`, `t+60분` 값으로 재계산했고 1,000행 모두 일치했다. 양성 500행은 모두 현재 값이 90% 미만이었다.
- 층화 표본이라 전체 비율을 대표하지 않고, 검증한 것은 이 1,000행뿐이다. 이번 표본은 재수집 원본으로 만든 파일에서 새로 뽑았다.
