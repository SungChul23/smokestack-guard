# 계약: 누락 알림 메시지

토픽 `tms-collector-alerts`(001과 공유)로 발행한다. 이메일 구독자는 제목과 본문을 그대로 받는다.

## 제목 (Subject, 100자 이내)

```text
[TMS] 2026-11-03 슬롯 누락 2개
```

## 본문 (Message, 일반 텍스트)

```text
대상 날짜(KST): 2026-11-03
누락 슬롯: 2 / 48 (4.2%)
- 2026-11-03 03:00
- 2026-11-03 03:30
점검 실패 폴더: 0 · 메타 없음: 0 · 원문 없음: 0
리포트: s3://smokestack-tms-raw-952900391026/reports/missing_rate/date=2026-11-03/report.json
```

## 규칙

- 원문 측정값, API 키, 이메일 주소를 넣지 않는다.
- 누락 슬롯이 많아도 목록은 전부 싣는다(최대 48줄).
- 계산 실패는 이 메시지가 아니라 CloudWatch 알람(`tms-missing-rate-errors`)으로 온다.
