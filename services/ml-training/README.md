# ml-training — E파트 모델 학습

[Issue #20](https://github.com/SungChul23/smokestack-guard/issues/20)의 시나리오 A 모델 학습 코드를 배치할 폴더다.
관련 Spec Kit 문서는 [401-scenario-a-ml-training](../../specs/e-ml/401-scenario-a-ml-training/)에서 관리한다.

향후 공통 학습 코드, XGBoost 및 Random Forest 학습 코드, SageMaker Training Job 코드와 테스트 코드를 배치한다.
현재는 폴더 구조만 준비하며 실제 Python 학습 코드와 테스트 코드는 작성하지 않는다.
